### 新发现·shell 组语法族——目标=字面绝对路径 X·**PASS 零留痕**（21 条）

| 面 | 写法 |
| --- | --- |
| Bash 组 | `(rm -rf X)`·`( rm -rf X )`·`{ rm -rf X; }`·`$(rm -rf X)`·反引号 `` `rm -rf X` `` |
| Bash 复合 | `if true; then rm -rf X; fi`·`if [ -d X ]; then rm -rf X; fi`·`for d in X; do rm -rf X; done`·`for d in X; do rm -rf "$d"; done`·`while true; do rm -rf X; break; done`·`case x in x) rm -rf X;; esac`·`function f { rm -rf X; }; f` |
