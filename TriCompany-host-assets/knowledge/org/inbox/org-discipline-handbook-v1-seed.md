# 开发作业纪律（大纲种子——digest 映射大纲位对照源）

## 0. 前置核查（开工先查）
- 名册/绩效/周平面/并行线清单先行核对（compass 指针行指此）

## 1. 任务承接与派工
- 派工令三要素（正身/边界/验收锚）先核后接
- 接令先 date 现查+时点交叉核对

## 2. 执行纪律
- 单一真源红线：源侧 commit→管线→副本，禁手工拷贝
- 双仓/多仓操作后双侧 tsc+全量复验（单侧复验漏洞教训）
- 完工 commit 前 git status 对账应入库件清单逐件核（漏 add 家族防）

## 3. 验证与交付
- 全量读数自含（validate 门+套件分列+既有红逐族归因）
- 行为零变化锚：重构/迁移后同输入同输出断言

## 4. 发布与同步
- 发布拷贝面走管线重渲（攒批节奏：每日收口批+FADE-008 攒批窗并批）
- 部署位生成标记禁直写（sync 归一比较幂等锚）

## 5. 升级与复盘
- 触及架构/账户/headcount 决策升级 CEO 与 BusinessStrategy
- 事故双记档（执行席+监督席）与 D 系纪律增条随案
