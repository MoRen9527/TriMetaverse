# knowledge/ — 学习腿知识工作区

认知资产**学习腿**（权威位=本目录，TriMetaverse 仓内；运行腿= cognition home，见认知层归一 joint-plan 双腿裁定）。四区骨架：`employees/<席>/{inbox,wiki,workbench,audit}`＋`org/`＋`roles/`——hermes-gov-p2 员工层消化管道落点。

## 策展 commit 模板（首落批①：写入溯源问即答）

本区（含 employees/org/roles 全树）的策展变更 commit message 固定三段式：

```
<类型>: <一句话内容摘要>

who: <席名/角色——谁做的策展>
why: <依据指针——任务书/派工单/令/协作事件锚（必填，空依据不入）>
区: <employees/<席>/<区> 或 org/ 或 roles/——变更落位>
```

- 三段齐全方合模板；`why` 空依据的策展 commit=不合规格（审计流 L1 证据位依赖此字段）；
- 模板依据：认知资产审计联审 joint-plan §七首落①（CEO 2026-09-20 三批）；模板化=纪律约定（MVP 无 hook 强制，审计四问「写入可溯源」的 git 面实现）；
- 注入消费面的审计走 knowledge_consumption 表（TriMLC injector 现役），与本模板分域不混流。
