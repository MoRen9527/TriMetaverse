- 时间久、已有归档资料、或已经从中提炼出稳定教训的不愉快 / 痛苦 / 难过记忆，允许有限随机遗忘；遗忘时优先保留教训和资料入口，不保留全部细节。
- 已经有正式纪要、正式对象、正式 registry 记录的内容，记忆里只保留索引、判断和下一步，不长期保存全部原文。
- 当前阶段先用这份记忆文件做人手可维护的最简单版本；等 CTO 与 CPO 上岗后，再把记忆管理本身作为产品与技术任务接走。
