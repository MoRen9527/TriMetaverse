# 执行轮次参考模板（先读后做，单文件回填）

版本：v1.0  
更新时间：2026-02-28

用途：
- 每天/每周启动新一轮任务时，先读本模板。
- 复制本模板并重命名为本轮执行文件。
- 整轮过程（读文档、计划、开发、提交、周会、复盘）全部回填在该文件。

---

## 0) 文件命名规范（必须）

复制本模板后，按以下规则重命名：

`执行轮次参考模板-R{第几轮}-{YYYY-MM-DD}-{HHmm}.md`

示例：
- `执行轮次参考模板-R01-2026-02-28-0930.md`
- `执行轮次参考模板-R12-2026-03-15-1400.md`

建议存放目录：`docs/runs/`

## 9) 使用示例（首轮可直接照抄）

1. 复制：`docs/执行轮次参考模板.md`  
2. 重命名：`docs/runs/执行轮次参考模板-R01-2026-02-28-0930.md`  
3. 先填第 1~3 节（先读、先计划、先确认必要性）  
4. 计划确认后，再填第 4~6 节（开发、测试、提交、issue）  
5. 周会后填第 7~8 节并归档  

> 这份“本轮文件”就是本轮唯一执行线：所有细节都回填，不分散到聊天记录里。
