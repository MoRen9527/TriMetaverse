## 5) Status 建议枚举

- `TODO`：未开始
- `IN_PROGRESS`：进行中
- `BLOCKED`：被依赖/问题阻塞
- `REVIEW`：开发完成待评审/验收
- `DONE`：完成并通过验收

## 6) 周会更新规则（建议）

- 每次周会只更新三项：`Status / ETA / Blocker`
- 每个里程碑至少保留一个“风险兜底任务”
- 若某任务 `BLOCKED > 2 天`，必须在 Epic 中补充绕行方案
