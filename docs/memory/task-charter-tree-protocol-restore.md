CEO 2026-09-14 指正+立规：任务书→挂周工作平面→face 路由（server-executable/local-executable）→自动拾取→拆多树→每树一文件夹→每节点收口报告——此为**执行层标准流程**（FADE 管线的 D/E 段本体，W37 trees/ 一直在跑，是 BOD 派工漂移没把活喂给它）。条文：①凡可自含打包的执行任务一律立任务书挂平面走树协议；②台账销账记录必附树路径+收口报告指针（两层以指针缝合：台账=记账层，树=执行层）；③对话式派工仅用于裁决交互链，事后按任务书格式补档。
