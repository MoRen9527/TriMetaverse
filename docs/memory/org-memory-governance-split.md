CEO 规则（2026-08-27）：涉及**项目或公司维度**的相关事项（架构事实、部署拓扑、工程纪律、运行语义），记忆要写入公司或项目治理真源——写到哪由小贾判断：

- 跨域通用纪律 → `TriCompany/docs/workflow/engineering-disciplines.md`（D-xx 编号条目制）
- 项目技术真源/设计语义 → `TriMetaverse/docs/execution/` 对应设计文档
- 服务器运维拓扑 → 相应 runbook 或 execution 侧文档

**Why:** 会话记忆只有编排层自己可见，TriLC/TriMC 侧员工与后续实例读不到；组织资产必须可被全员知识通道引用。

**How to apply:** 写记忆前先分类——"我该怎么协作/行事"留这里；"世界是怎么运转的"进仓库并落 commit。个人侧同类文件保留时降级为**指针**（指向仓库真源）。相关：[[engineering-disciplines-home]]
