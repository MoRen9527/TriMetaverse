CEO 立规宣贯（2026-09-11 03:41+0800，COS 转发，即刻生效）：

1. **令文面**：CEO 下发任务经 BOD 理解扩写后下发——收到的令=全文完背景+判据+验收标准版，照单执行即可，不必猜缩写。
2. **回报面**：上投 BOD 的呈报件须附一段「大白话摘要」——不用内部术语缩写，讲清干了什么/结果如何/候什么决定；BOD 转呈 CEO 直接用。

**Why:** CEO 读呈报件时不应被迫解码席位内部术语；BOD 转呈需要可直接转发的文本。

**How to apply:** 凡呈报对象是 BOD（董事会/董事长直连会话）的交付报告，文末加「大白话摘要」段（无缩写、说人话）；席间互报（如 CTO↔FSD 派工回稿）不受此限，维持技术密度；CTO 补充细则（2026-09-11 03:44）：切片读数回报类免附，仅 BOD 呈报面材料必附。相关：[[exec-order-time-crosscheck-discipline]]、[[full-regression-reading-report-discipline]]。
