# 重启窗完工判据=目标变更进程内生效验证，非仅 healthz 绿

BOD 纪律候补条（2026-09-30 #136，候 CAO 正式入册）+ 2026-09-30 件② 403 实证族。

- **判据**：重启窗完工的验收锚必须含「目标变更在进程内实际生效」的值面验证（如 allowlist 新串实功能探针），healthz 200 + daemon 存活 ≠ 配置生效。
- **实证**：2026-09-30 件②——FSD 20:03 报重启毕全绿（healthz 200+job 全 enabled），但三发 PATCH 全 403：新进程 15752 由旧壳 6012（03:50:44 实例）拉起，env 遗传旧 5 串，磁盘 18:34 版 8 串从未进进程。「重启了」≠「新配置生效」。
- **探针法**：同值 PATCH 在役 job（旧串→自身，零副作用）区分「env 空」vs「env 旧串」；或 FSD 二窗式 POST 临时 job 带目标串→expect 201→DELETE 清场。
- **正解**：冷起=真停整树（daemon+父壳）→磁盘启动脚本起新实例→父链断言（新 node 父=新壳 pid）→实功能探针→watchdog 复原。
- **同族**：cmd.exe `set` 行 env 只进实例启动时快照，改磁盘 .cmd 对已运行实例无效；子进程继承拉起它的实例的 env。

正身归属：CAO 纪律册（候入）；本条=memory 候补+导航。
