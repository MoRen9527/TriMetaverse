长会话（跨越数小时或数天）中，我在某个时点形成了错误的日期锚点（如认为今天是 08-26 而实际是 08-25），此后**所有**新时间戳都基于错误锚点外推，导致落盘文档日期全错、排期表述混乱、甚至"夜深了收工"但实际是傍晚。

**Why:** 会话上下文中的旧时间读数会被大脑当作"当前时间"持续使用；跨零点/跨天后如果不主动重查，锚点永远不会自动更新。

**How to apply:**
1. 每次写任何带日期的字段前，必查 `date` 命令获取当前真实时间
2. 跨零点后首个动作=重查 date 并显式声明"已进入新的一天"
3. 长会话每隔 4-6 小时重查一次锚点
4. 如果 CEO 纠正了时间，立即用 `date` 核实并修正后续输出
