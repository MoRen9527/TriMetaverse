CEO 立规（COS 宣贯 2026-09-11 03:41+0800 即刻生效）：

①**令文面**：CEO 下发任务经 BOD 理解扩写后下发——收到的令=含完整背景+判据+验收标准的全文版，照单执行即可，不必猜缩写。
②**回报面**：**上投 BOD 的呈报件须附一段「大白话摘要」**——不用内部术语缩写，讲清三件事：干了什么／结果如何／候什么决定，BOD 转呈 CEO 直接用。内部席间互报（晨检/联审协作件等）不受此限。

**Why:** CEO 不在席位术语上下文里，术语密集的呈报件到 BOD 转呈层会失真或需二次解释；大白话摘要让转呈零损耗。

**How to apply:** 凡收件人=BOD（m-bod）或经 BOD 上行 CEO 的呈报，末尾固定加「大白话摘要」段：三句话以内、零缩写（TriRLC/LG-xxx/host 这类词要么不出现要么顺带半句解释）、直接回答「干了啥/成没成/等谁拍板」。席间协作件（m-coo/m-fsd/m-cos 等）照旧术语密度不设限。关联 [[bod-date-check-before-report]]（同一上行通道的报时纪律）。
