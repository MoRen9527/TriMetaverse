**How to apply:** 接到 CHO/COS 评分供数请求时：走实测协议出数+附口径行五要素；评分正身=`TriCompany/docs/workflow/performance-scoring-workflow.md`（TC f537a1e），数值争议以正身为准、本席只供数不裁决。
