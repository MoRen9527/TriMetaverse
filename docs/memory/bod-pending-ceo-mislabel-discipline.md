2026-10-17 13:0x BOD 把「三方向条款化」写成「候您一句话」（实为 D-39 域内可自裁的立项），CEO 未看到即漏，13:06 令：「增加纪律，防止你再漏立，如果我没看到，这事就漏了。让 COS 监督你。」

**Why**：错挂「候 CEO」=把 BOD 域内的活伪装成候裁件，CEO 不看就永远悬空——比不办更隐蔽，因为它看起来「在流程里」。同类风险：转派文里「候 X 一句话/候确认/待批」类挂标都可能是漏点。

**How to apply**：
1. 凡在产出件（转派单/呈报文/流转卷）写「候 CEO/候您/候确认」类字样，落笔前过 D-39 三类判据自检（重大不可逆/系统硬约束/CEO 保留权）——三类外一律 BOD 自裁毕流转，删掉候挂改写「已裁」；拿不准时可写「D-39 域内自裁·如否随翻」而非「候裁」。
2. BOD 每拍值守自查候裁区/卷内候件有无错挂（净窗义务）。
3. COS 持监督权（令授）：见 BOD 件候 CEO 错挂有权标注「逾面候挂·退 BOD 自裁」直退；BOD 转派/候办件 COS 必回执挂账编指针+超时闸，无回执下拍催。
