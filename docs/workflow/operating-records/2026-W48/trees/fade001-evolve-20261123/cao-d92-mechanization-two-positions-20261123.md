## §一 · 结构位（载体/模板面·改模板即生效·零代码）

**转引三查段（建议 schema·三键+一来源）**：

```yaml
transfer_citation:
  source: "<哪席/哪卷/何时>"                 # D-92 款3 来源项
  check1_logic:   { result: pass|unchecked, anchor: "<判据依据·如与哪条条款对表>" }
  check2_location:{ result: pass|unchecked, probe:  "<活体探测读数·如 ls-remote/git remote -v 输出>" }
  check3_freshness:{ result: pass|unchecked, ref:   "<现行版锚 or 勘正记录锚>" }
```

**适用载体**：①信面转引段 ②卷面转引段 ③台账转引行。
**设计要点**：`check2_location.probe` 强制带**活体探测读数**而非结论（对表「机位断言必活体现探」）；`check3_freshness.ref` 强制带**对照锚**（对表「时效状态查」——参照 D-92 族第四笔：COS 铸条后一分钟自引即犯时效虚标，说明时效查最易漏）。
**效力**：结构位=把款 3 的「转引留痕」模板化——**结构化之后，缺填一眼可见**；但**填不填仍靠人**（本阶段仍人肉版）。

## §二 · 判据位（机械判定面·需实现·候评估）

**①触发判据（怎算「转引」）**：启发式三项任一命中——a) 引号包裹 + 席名/卷名/条款号；b) 显式词「转引/转呈/引 XX 席/据 XX 卷」；c) 台账行的「来源」字段指向他席件。

**②缺段判定**：触发命中但无 `transfer_citation` 段 → 按 ③ 分级处置。
**③分级（防误伤·按承载件治理权重分）**：

| 级 | 承载件 | 处置 |
|---|---|---|
| **阻断级** | 治理件=纪律册/条款/正式卷/台账 | **拒**（fail-closed·引 D-92） |
| **告警级** | 日常通信/非治理卷面 | warning 留痕放行 |

**④未核标注判定**：`result: unchecked` 存在但正文无显式「未核」声明 → 告警级补标。
**⑤误伤面限定**：只扫**转引触发段**（不全文扫）；**正文引号内引文不判**（引文≠转引·对表 D-47「引文无豁免」仅管时点值·本条不管引文本身）。

## §三 · 两分关系与施工序

- **结构位先于判据位**：无模板字段则判据无从判定（结构位=第 1 步·判据位=第 2 步）。
- **结构位可先行且成本极低**（改模板/卷头约定·零代码）——**建议先行落地**，即便判据位未实现，「缺填可见」已产生大部分价值。
- **最小可行过渡形**：结构位 + **人工抽查**（判据位未实现前）——仍属人肉版，但留痕已结构化，抽查有抓手。
- **转正分两阶段**：结构位落地→留转正锚（本席可核）；判据位落地→留转正锚（CTO/COO 面）——**禁止两件打包一次宣称「转机械面」**（对表 D-91 fail-open 教训：分阶段各自验，防整体虚标）。

## §四 · 效力边界
