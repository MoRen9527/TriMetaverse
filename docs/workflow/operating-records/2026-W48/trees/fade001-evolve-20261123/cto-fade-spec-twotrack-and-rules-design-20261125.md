## §二 · 功能一规格：「计划执行规矩」（plan skill 规划规范+dce 执行不偏）

**现状**：plan skill 产 plan.json（承接树/counts/posterior）；dce 按 plan 执行——**规矩散落**（D-90 的段合同/族点名/标签/carry 等隐式约束·无统一可检验形）。

**改法（规矩形·可检验）**：
1. **规划规矩（plan skill）**：6 条可机判结构面——a) **族点名齐全**（improvements 的 target 族名 ∈ 表内枚举）b) **标签非兜底**（owner_seat/covered_dims 非缺省占位）c) **carry 四字段齐**（carry_over 的 keep/live/reason/dest）d) **考卷锁定**（exam 卷 hash 入 run root 引用集·Plan 时点冻结）e) **双向断言**（plan 的 counts 与树面实测双向对表）f) **plan-freeze**（v8 item9·四字段底线+复算门·已落）。
2. **执行规矩（dce）**：**执行不偏 = plan vs 实际 diff**——多用/少用/错序三型机判（步骤集对比·cli 可判）+**dce 四步真跑 rc/产物齐**（已落·dce execute 开关）。
3. **落点**：plan_skill_spawn（规划规矩断言·f 已落·a-e 增）；dce_steps（执行不偏 diff 面增）。

## §三 · 功能二规格：「计划评分执行不偏规矩守住」（评分体系·对齐两轴）

**判据四格（CPO 四格表·技术落法）**：

| 格 | 判据 | 判者 | 落点 |
|---|---|---|---|
| ① 执行不偏 | plan vs 实际 diff（多做/少做/错序） | **cli**（机判） | score_engine 新族/或 D 族扩 |
| ② 规矩守住·结构面 | 族点名/标签/carry 四字段/考卷锁定/双向断言 | **cli**（机判） | 同上（结构断言族） |
| ③ 规矩守住·语义面 | 偏差是否合理/规划合理性/偏离处置恰当 | **skill**（rationale 必填） | I 族题面扩或新主观题 |
| ④ 真空 | 偏差显式但理由编的 | **cli 初筛（evidence_ref 存在性）+skill 复核** | 双判：cli 先筛空 evidence_ref·存活项 skill 复核 |

**闭环必要性**（CPO 提示承）：只有①②=「规矩只对结构不对语义」**可被形式化应付**——③④两格=闭环必需。

**对齐两轴**：①②④的 cli 部分=**验收轴**（80 线内机判族）；③+④的 skill 部分=**I 族主观**（score_skill）；**联审 A/B=进化轴**（不动验收轴判定）。
