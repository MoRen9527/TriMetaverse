## 问① UI 直连配置页：定位、边界与护栏（产品主场）

### 定位（一句话）

「**连接配置**」页——管理本机 Claude Code 连到哪个后端。不叫「直接编辑 settings.json」：文件名是实现细节，用户心智是「我的 AI 助手连到哪」（cc-switch 心智＝切换器，不是文本编辑器）。

- **日常便利层**：3333 在线时用，做三件事——看（当前连接形态）、切（模板/形态切换）、回（一键回滚）。
- **不担兜底**：页面自身依赖 3333，按零自依赖铁律天然没有兜底资格；兜底=带外命令族（问③）。
- **敢让你改，就敢让你一键回去**：MVP 必含「回滚到上一备份」按钮——这是便利层的自信，也是事故案「备份在手边未用」的 UI 化解法（把回滚做成零思考动作，不要求用户记得 bak 文件名）。

### 功能边界（允许/不允许清单）

**做**：
1. 读＋展示当前 settings.json 的 **env 连接子集**（BASE_URL/AUTH_TOKEN/API_KEY 等预设覆写键）与当前形态判定（direct/relay/自订）。
2. 模板切换（模板三件套，见问③）——「选目的地」不是「填表格」：选模板后只填钥一个必填项，地址/模型名模板自带，高级覆写折叠收起。
3. 备份列表查看＋一键回滚到指定备份。
4. 写路径五门（下节）。

**不做**（负面清单同样是产品承诺）：
1. 不碰 env 子集以外的任何键（最小侵入，与 restore v2 同语义）。
2. 不显示、不导出、不记录完整凭据（掩码见下）。
3. 不装软件、不建 proxy、不动 3333/watchdog/daemon 进程。
4. 不提供「任意 JSON 文本域直接编辑」——自由文本编辑=绕过全部预检门的事故入口，本页一切变更走表单＋模板形。

### 写路径五门（吸收 09-25 事故教训，逐条对事故缺陷）

| 门 | 内容 | 对应事故教训 |
|---|---|---|
| 1 凭据掩码 | 默认 `****`＋尾4位；diff 预览里凭据行只显示「已设/未设＋尾4」；全值永不进前端日志/RESULT 行 | 凭据暴露面收敛 |
| 2 写前预检 | JSON parse 合法＋凭据非空/非占位符（PLACEHOLDER/空串/纯空白三态全拒）＋必填字段齐＋键形校验；任一不过=拒写并用人话说为什么 | 修-1 空串直放=事故直因 |
| 3 diff 预览确认 | 提交前展示将改的键值 diff（凭据脱敏），用户确认才落笔——`-WhatIf` 的 UI 形 | 修-3 干跑纪律 UI 化 |
| 4 备份先行＋幂等短路 | 时间戳备份锚（轮换留 5 份沿用现役口径）；**无变化不写不备份**（同值重复提交=提示「无变化」零动作）——事故案 5 分钟五连备份的备份风暴教训，回滚锚不能被噪音淹没 | 事故案五连备份 |
| 5 写后回读断言＋自动回滚 | 写后回读：凭据非空＋值与提交一致＋JSON 合法；任一失败=自动用本次备份拷回＋红条报错 | 修-4/O-2 断言域收窄口径沿用 |

补充一条体系级原则（问② L2 钥源同款）：**钥不生于钥要去的那个文件**——凡自动写活体的环节，输入钥源必须独立于被写对象（事故教训②死循环取钥的一般化）。

### 与 LG-035 policy/card 冻结面的分界（四条，防误触）

1. **对象分界**：本页=客户端连接层（`~/.claude/settings.json` env 子集）；LG-035 冻结面=服务端路由层（TriModel provider/model 策略、卡 v4、生效值）。两层对象不同，字段零交集。
2. **交互分界**：本页不改 policy/卡/生效值任何状态；至多只读一行展示「当前生效形态」并链接跳转，不提供任何策略编辑入口。

## 问③ 跨平台命令族（产品主场：人话可用性；四族并案）

### 命名：四族=名字即拓扑（好命名，予以确认＋一颗现役雷）

`trimlc/trirlc/trimmc/trirmc` 与四 daemon 同名同形，机器×域自解释，产品面确认。**但现役事实雷**：TriMLC 仓 `package.json` bin 现名=**`trilc`**（旧名遗留），TriRLC 仓（原 TriLC）bin 大概率同名——一机双族若都叫 `trilc`，PATH 冲突与心智混淆立现。**正名不是可选项**：bin 必须随命令族正名（trimlc/trirlc），旧名 alias 过渡一版＋弃用标注。此项属实现面，归 CTO 裁，产品面只立判据：**用户敲的名字、daemon 的名字、仓的名字三者一致**。

### 命令面（MVP 三件＋一件建议）

- `trimlc restore`——恢复直连。**零参数＝安全侧默认**（缺省 direct，沿用 restore v2 缺省）；`-Mode relay` 切回中转。
- `trimlc config show / set / template`——配置参数。set 走与页面同款五门（同一套预检内核）；template 列出/选用模板三件套。
- `trimlc status`——状态查询。输出人话三段：我现在什么形态／各层健康（3333 探活、daemon 存活、钥源健康）／有没有需要我做的事。**零参数只读**。
- 建议第四件 `trimlc doctor`（一键自检，把分层健康汇总成一句结论：「你现在安全／已降级直连／需手动干预」）——可与 status 合并实现，不扩 MVP，产品面留位。

**全族形态三统一**（跨三机四族的产品判据，实现形态 CTO 裁）：同一命令语法、同一 RESULT 行格式、同一人话输出风格——restore v2 的 `RESULT/FAIL` 结构化行（op/mode/target/backup/assert/smoke/ts）是本机已验证的好形态，全族沿用，学的同一套用的同一套。

### 模板三件套（地址/模型名/钥占位符）

## 问② 分层监督链（CTO 主场；产品面三条边界意见）

1. **探活探针语义=用户可感知性**：「重启无效」的判定探针（GET /ui 200 之外）建议含一条**业务层探针**（如生效值接口返回合法策略）——端口活着但业务死着的状态，用户视角=不可用，L1→L2 判定应对齐用户可感知口径，防「探针全绿但用户全红」的假健康。
2. **L2 自动降级的用户告知不可省**：自动降级是系统替用户做的重大决定（换后端了），必须留下人话痕迹——toast（L3 形）＋status 可查＋RESULT 行留档，「静默降级」=下次事故时没人知道现在是什么形态。**诚实 UI 双原则**照用：物理不存在的状态不伪造，物理存在的时延不隐瞒。
3. **L3 toast 文案四要素**（D-29 无窗纪律照挂，禁闪 conhost）：①出了什么事（3333 不可用，已自动降级本地直连）②现在什么状态（服务不受影响，走直连）③要你做什么（无需动作 / 运行 `trimlc restore`）④去哪看详情（`trimlc status`）。禁术语、禁恐慌体。
4. 独立钥源 `.deploy-key` 衔接＋禁活体死循环取钥：产品面背书为体系原则（见问①「钥不生于钥要去的那个文件」）。

## 问⑤ 部署面 R-HY（产品形态）

1. **关系裁决产品意见：分域并存，非主备**。R-HY=R 面服务域配置中枢；本机 3333=本地开发实例（开发形态保留，降格为「开发/演练位」并在 status 文案里如实标注），不承担生产配置职责。M 面服务域中枢按现势在 sg 域（TriMMC 侧），与 R-HY 各管各域。
2. **本地实例退役节奏=判据制，不是日期制**：①R-HY 连续稳定运行（探活零 P1 达 N 天，N 候联审定）②两面消费端配置全部改指服务域中枢（下发通道毕）③回退窗显式关闭（本地实例保留只读镜像一版候查）。三判据齐才动退役；**退役前「本地直连=唯一本地恢复锚」地位不动**（问⑦衔接，CEO 定调，产品面升格为红线）。
3. **配置真源唯一**：每域一个真源位（R面=R-HY，M面=sg 域中枢）；本地 settings.json=消费端投影，不是真源。这个定位写死，防「两处都能改配置」再度打架（LG-035 单一真源教训的一般化）。产品验收问句：「这个配置改了之后，谁 authoritative？」答不出=设计没完成。
4. **存储与下发通道产品意见**：集中存（域中枢为真源）＋**拉取为主**（消费端/daemon 拉真值，本地缓存最近已知好配置；拉取失败不阻塞本地运行）＋推送只做「配置已变更」的指令通知。拉取失败静默降级用本地缓存=与恢复梯天然同构。

## 问⑥ 网络与安全面（鉴权与通路的用户体验，产品主场）

1. **token 门**（禁裸奔照令）：产品面补生命周期三动作的人话化——生成/轮换/吊销，各一条命令或页面一键；token 全值**只在生成时展示一次**，此后一律掩码；轮换须有**双 token 并行窗**（新 token 验证生效后再废旧——防轮换自锁把自己锁门外，auth 自锁教训的一般化）。
2. **通路失败的用户话术**：本机→R-HY 通路超时/不可达时，status 与页面必须给出明确人话（「配置中枢不可达，正用本地缓存配置运行，不影响当前使用」），禁转圈、禁裸错误码。
3. **两域路由模型的产品形态：人不记 URL、不选路由**——路由表归 daemon（TriMLC/TriRLC 各管各域），人看 `status` 的人话结论；页面只展示「本域消费者当前指向」＋预设形态一键切换。**人为手改 URL 是 L4 兜底态，不是日常态**——这条定位决定页面和命令族的菜单深度（日常动作零配置项，兜底动作才露高级项）。
