## 增补条正文（草案）

**派工到达确认机制（三闸之三「防断」）**：

1. **接令回执强制**：树协议每一环（cos→coo→执行席、跨环转投、代转、补投）派工后，须获执行席**接令回执**（确认接手）方算派工闭环——无回执=未到达（断链态）；**「已发」不构成「已达」**；
2. **断链处置**：无回执超 **30 分钟**=派工断链——派工方即刻补投或改道；仍不通上呈 BOD；
3. **断链检测兼职**：m-duty-cos 30min 催办循环兼任断链检测——发现「宣称派工但执行席无接令回执」即报 BOD；
4. **衔接注记**：本条系 D-15 分派枢纽纪律「接令须回执确认接手」从枢纽纪律**扩展为树协议全链强制**（每一环均适用，含代转/补投形态）；
5. **三闸成套**：本条（防断）＋「批准后 48h 派工时限」（防漏）＋「派工前置对表」（防重）＝树协议派工三闸，成套适用。
