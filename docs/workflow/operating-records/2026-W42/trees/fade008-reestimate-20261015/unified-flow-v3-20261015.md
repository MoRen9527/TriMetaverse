### 拾取与拆树（Q7·核心）

- 拾取**任务书**三校验：①原始态在周平面（登记在案）②charter-id 幂等查重 ③face 值在四面矩阵内——任一缺→拾取失败回声总调度（**执行端不倒补不代登记**）。
- 校验过→拆 n 树：**拆树粒度=任务书内独立可验收工作包**（必收口③·COO 执行域面定）——charter-id:tree-id=1:n·树=执行域产物·审计/恢复锚跟执行域（活与锚同域）。
- **粒度四则（COO 终稿定形·拆树时逐则对表）**：①独立可验收（单树单验收锚·可独立判毕·验收判据入树面）②单一 owner（单树单值席·不跨席·跨席工作包拆两树）③工时上界（单树≤2h 试行·候 CTO 对表校准）④依赖显式（树间依赖在任务书面显式声明·禁隐含顺序）。
- **n 值边界**：n=1 合法（平凡件退化单树）；n 无硬上限·n>5 时总调度出拆任务书建议（级联候选·拆分裁决归 COS 备料面）。
- **拆树时点**：拾取三校验过后·拆 n 清单（树表）挂任务书面·总调度复核后才进值席流水线——拆树权=执行域（Q7）·复核权=总调度。
- 服务域拾取形态对称化：M 面 TriMMC 值席脚本序+sg 箱巡检（现役先例=夜航01/批令执行波）；R 面 TriRMC 同构。

### 回声与 SLA（COO v2 §五/§六承）

- 回声双锚：树毕报落执行域树+台账销账必附**执行域树指针**（n 树=树束逐指针或树束索引·缺不得销账·销账唯 COS）。
- 任务书原始态两分离（登记位不迁移·执行状态随回声更新）。
- 跨面流转：R 面毕报经 BOD 各 COS 流转回（转发即域定·不跨面直投）；G2 转域件树移交新执行域·指针迁移随改判记录。
- SLA 表：备料→登记当日／G1 终裁≤当日／拾取校验≤1h／本地轨单件≤30min（超→G2）／树执行段按任务书 SLA 逐树计。
