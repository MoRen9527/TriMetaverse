## 一、设计：席级考核=FADE 实例

**核心映射（CEO 定谳方向逐条落位）**：

| FADE 段 | B2 考核面 | B1 共用面 |
|---|---|---|
| 事件/登记 | 考核周期触发（月度/批次） | 受托任务入树 |
| Qualify | 考核范围圈定（该席该考什么=映射表行） | 节点动作资格 |
| Plan | **试卷（Plan 时点冻结）**=考核卷：①测试集=该席「典型交付物」清单逐项验法（LG-074 A 类批产物直接供料）②双门槛要素+双 hash 冻结（防自改考卷） | 节点 brief 简报约定 |
| DCE | 受托交付执行 | **答卷=B1 受托交付**（brief+checkpoint+artifactCommit git SHA+工件清单 R-C3） |
| Verify | 交付物齐整性核验 | — |
| Score | **考试判卷两段**：Score CLI=交付物清单覆盖确定性检查（是否遗漏，omission 字段）+Score Skill=质量语义评定（每项处理质量）→评分 JSON 两源合并 | — |
| Close | **账面回写**=scoring 四要素落账（缺陷扣分←Score Skill 缺陷项/验证加分←验证锚项/干活量比例底分←DCE 工件量） | 台账销账链 |

## 二、职责↔scoring 映射表（模板+样例三席，全表候会签后扩全）

| 席 | 核心职责条目（agent-body） | 考核读数源（典型交付物行） | scoring 四要素挂钩 |
|---|---|---|---|
| CTO | 交付纪律守底线（门禁/回滚） | 质量门禁读数与放行判定 | 验证加分：门禁判定附测试证据；缺陷扣分：漏判/误判放行（Score Skill 语义评定）；干活量底分：DCE 工件量（方案+registry 更新数） |
| CHO | 交接验收链路 | handoff checklist 签收记录 | 验证加分：签收附验证锚；缺陷扣分：裸签/链路漏环（六环缺一）；干活量底分：验收件数 |
| CFO | 预算护栏 | 护栏表+burn 读数 | 验证加分：读数对轨可复算；缺陷扣分：口径漂移/虚假精确数；干活量底分：护栏维护与审查件数 |

- 成本读数同源（CFO 会签点）：干活量比例底分的消耗读数与 CFO 账面**同源**（CFO 按「面+服务域+账户+模型」四元键供数），CHO 不得另立口径——本表落地时每席底分公式中的量纲须 CFO 会签。
- 实例化路径：候批后按 fade-registry 立实例规范（如 FADE-PERF-XX 席级考核实例），每考核周期一实例一卷一评分，收口报告入台账——「完善每一个 FADE 实例」的方向承接。
