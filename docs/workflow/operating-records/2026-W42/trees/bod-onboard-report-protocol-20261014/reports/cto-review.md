## ①cron session-only 特性与报到时机匹配——成立·附一条升级条款

- **闭环成立判定：成立**，机理=重启后复活体首回合读身份面→见报到约定→报到→CAO 发上线工作（重挂 cron 等）→领单恢复——报到制本质是「复活后状态重建链」，与 session-only 特性精确互补（session-only 丢的正是运行态，报到制重建运行态）。
- **成立的前提条件**：复活体首回合必须能看到报到约定——约定必须注入复活体启动上下文（system prompt 链），否则闭环第一步即断。这是审点②落点问题的决定性约束（见②）。
- **附升级条款**：报到无应答升级链（详见共同审点 c）——无此条闭环在 CAO 缺席面开口。

## ②source-agents/board/ 落点——agent-body 正落+contract 引用留痕·frontmatter 不放

- **正落=agent-body**（注入面）：报到约定是行为约定，必须在复活体 system prompt 注入链内才生效；frontmatter 是元数据/工具面不进行为上下文；contract 是契约真源但注入链不及 agent-body 直接。
- **contract 加一行引用留痕**（「上线报到义务：见 agent-body〈上线报到〉节」）——契约面可追溯·行为面可执行，两件配合不重复。
- **与 10-13 三件套修订衔接**：报到约定作独立小节（建议节名〈上线报到〉）置于 agent-body 尾部、渲染管线常量段之前（照 M-001 段先例·段体零夹带）·不动既有节——修订刚毕的节结构零扰动。泛化时同节模板复制到其他 agent 的 agent-body。

## ③daemon 机械兜底——保留候补·降频·与报到制正交

- **判定：保留**。报到制盖不住的三类场景，只有机械兜底覆盖：
  1. **复活本身失败**（launch 失败/宿主问题）——无复活即无报到，报到制对此零覆盖；
  2. **CAO 与 agent 双静默**（报到发出但承接端同时死）；
  3. **宿主睡眠冻结段**——行为面与行为面同冻结（今晨 l1 探针 shutdown 窗同步失明实证：探针 job 与 daemon 同生命周期，冻结窗内行为面全部失明；机械 tick 面若挂 8713 同样冻结，但作为候补与跨面机械探测仍有价值）。
- **保留形态：降频候补**——原三案的 8713 tick 陈旧探测不双跑常驻（省成本），作候补条触发条件=「报到制失守信号」（如 BOD 席位静默超阈值时启用机械探测）。平时不启用。
- **架构判断一句话**：行为面（报到制）治「复活后配置丢失」，机械面（tick 探测）治「复活本身失败」——两层正交，非替代关系。

## ④泛化技术边界——判据一句话

- **适用域判据：有 session-only 运行态需重建+无人格 workspace 恢复链的常驻 agent**。
- **在内**：BOD（四时点 cron+信箱巡检）·未来持有定时任务/订阅态的机构席。
- **不在内**：
  - **registry 型**——无状态、spawn 型、每次现读 registry，无 session 连续性需求，报到无意义（M-004 适用域条：registry agent 可 spawn·spawn 型无报到需求）；
  - **13 员工常驻人格席**——非「非人格类」；其 session-only cron 重建走既有执行单/锁笔注记纪律（R1 窗先例：锁笔注记全参数在卷→复活后按卷重建），与报到制两条线不混。人格席纪律已覆盖同等需求，勿双轨。

## 共同审点

### a. 与原三案关系——部分保留

报到制**取代**纪律条+载体行（行为面自愈优于提示面记忆）；**daemon 机械兜底案保留候补**（降频·见③）。原案存档件继续作候补正身。

### b. 泛化正身落点——两者并·先立后破适用

- **纪律册 D 系**：立报到制条款（治理正身·适用域判据+升级链+N 值）；
- **source-agents 通用件**：agent-body 〈上线报到〉节模板（行为面落点·各非人格 agent 复制）；
- **先立后破**：先立条款（新上线非人格 agent 即适用）·存量（现仅 BOD）随下一自然重启窗补约定，不强制一次性回填。

### c. CAO 缺席兜底——升级链+清单冗余双兜底

1. **升级链**：agent 报到→30min（两拍探测窗）无 CAO 回执→升级 BOD（通道常在·代发上线工作或转 COS 代行 CAO 职责）→BOD 亦无应答→升级 CEO 直连面。N 值与链序入 D 条款。
2. **清单冗余（CAO 单点消解）**：上线工作清单除 CAO 记忆外，**在 source-agents 通用件放一份只读副本**——报到无应答时 agent 可自取清单降级自挂+事后补报到回执。单点故障面即消。
