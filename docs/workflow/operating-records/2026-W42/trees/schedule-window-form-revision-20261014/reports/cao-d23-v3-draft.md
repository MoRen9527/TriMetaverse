## 二、修订条款（拟入 D-23 v3 增补段）

**款 1·默认直跑**：

1. 一般任务挂周平面树**即拾取即跑**（D-27 树协议原生形态）——候排池独立准入面**取消**；
2. 界面保持：直跑=树内即时执行，非对话式派工回潮（D-27 条 1「可自含打包一律走树协议」与条 3 对话式限界不动）；
3. 时段不再是排程前置：一般直跑任务不受双高峰时段约束（成本面自检建议保留，见款 3）。

**款 2·窗控白名单（四类·窗=独占+护栏·非排队准入）**：

1. **窗的定性改写**：窗=**独占资源面+护栏锚**（回滚锚/止损线/值守位齐备方开窗）——**非排队准入**；白名单外作业不设窗不候窗（直跑）；
2. **四类入白名单**：
   - ① **daemon 勘修/重启类**：8710/8711/8712/8713 勘修窗、席位重启窗、watchdog 操作（服务可用性独占面）；
   - ② **专注窗**：四卡窗类——深施工需连续不受扰时段（认定锚=原「单任务预期消耗显著高于日常交互量级」判据并入）；
   - ③ **批量 token 窗**：大 token 消耗批量作业（全量测试/批量 spawn/大规模文档生成/上下文重建密集链——原约束对象枚举并入此类）；
   - ④ **不可逆操作**：真删/覆盖无备份/对外不可撤回（D-39 不可逆族施工面）；
3. 白名单内作业须排窗（窗内独占+护栏齐备）；排窗时段参考见款 3。

**款 3·计价事实与排窗参考（原指导表语义平移）**：

1. **指导表保留不动**（计价事实表——v2 号位裁定先例沿用）：GLM 3×/DS 2× 双高峰与空闲半价事实不变；
2. 语义平移：原「排程指引」列由**准入规则**改写为**白名单窗排窗时段参考**——白名单窗尽量落黄金段（GLM 轨 18:00→次日 14:00 滚动循环/DS 轨 18:00→次日 9:00+午间辅窗，v2 双轨照旧）=成本护栏参考项，非禁令；
3. v2 黄金期排紧哲学**保留为参考**：对白名单②③类（专注窗/批量 token 窗）适用；对一般直跑任务降为成本自检建议（知情选择，不设卡）；
