## 〇·本稿核心主张（一句话）

把 FADE-008 从「攒批驱动的单面管道」改判为「**供料-执行分离的票面制**」：供料端（本地域·排工席）开票即拆树即供料，执行端（两面服务域 daemon/值席）拾票执行回声——攒批段废除，face 路由升为四面路由矩阵，拆树权收归排工端，窗/直跑双轨在 A 段分流。

## 三、A 段重判：攒批废·挂即供料·双轨分流

1. **直跑轨（默认）**：任务书生成后挂周平面树=拾取即跑（D-23 v3 正形）——无候排段无攒批窗。供料 SLA=**当日**（任务书生效同日挂树）。
2. **护栏轨（白名单四类件：daemon 勘修/重启·专注窗·批量 token 窗·不可逆操作）**：任务书窗位段→COO 排窗出令（白名单登记面 windows 段登记·机器可读）→窗内挂树执行。双段式必查（禁排区+黄金窗对轨）只对窗令触发——直跑件零触发（本席 SOP 对轨正形·COS 已会签）。
3. 两轨**分流点在 A 段·汇合点在 C 段拾取**——执行端对两轨无感知差异（拾到的都是「树锚+树目录」形态票面）。
4. COS 今晨候对轨注①（攒批 vs 直跑）随本判对轨：**攒批段废除·挂即供料**。

## 四、C 段重排：四面路由矩阵+拾取校验制

### 四面路由矩阵（face 路由字段升级）

| 路由值 | 面·域 | daemon·机位 | 适用 |
| --- | --- | --- | --- |
| `M-service` | M·服务域 | TriMC 8712（sg） | 可自含打包+不依赖本地会话上下文+M 面数据/作业 |
| `M-local` | M·本地域 | TriMLC 8713（本机） | cron/notify/信箱/巡检类·需本地会话链 |
| `R-service` | R·服务域 | TriRMC 8710（河源） | 可自含打包+R 面作业 |
| `R-local` | R·本地域 | TriRLC 8711（本机） | R 面 daemon 本体勘修/本地交互 |

### 路由判据树（三问前置）

1. **面归属**：任务数据与作业归属面（M/R）——跨面任务按主作业面定·列全值主面在前（M1 三律沿续）。
2. **域判据**：可自含打包+不依赖本地会话上下文→服务域；否则本地域（M1 核查表第 1 问沿续）。
3. **daemon 选择**：域内按职能——对象断言三问前置（daemon 名逐字/机面/独立仓——教训条·daemon 机位矩阵硬规则：8712=sg/TriMC·8713=本机/TriMLC·8710=河源/TriRMC·8711=本机/TriRLC·探错端口空回≠服务停）。

### 拾取校验制（拆树权收归排工端）

- 执行端 daemon/值席拾取时**只做三校验**：①树锚在（令文带树锚）②树目录在（排工端已立）③幂等键查重（任务书 ID 主键去重沿旧）——**不做拆树不倒补树**（D-27 v9 正形）。
- 三校验任一缺→拾取失败回声（缺树锚/缺目录回声给排工端补·执行端不补）。
- 服务域拾取形态对称化：M 面值席脚本序+sg 箱巡检（现役先例=夜航01/批令执行波）；R 面同构（河源值席+TriRMC cron）。
- COS 今晨候对轨注②（拆树时点归属）随本判对轨：**排工端·D-27 v9 对齐**。

## 五、E 段重排：回声双锚+跨面流转+交接正形

1. **回声双锚**：节点毕报落树（树文件夹·持久化锚点非会话内存——§5.6 沿旧）+台账销账必附树指针（缺指针不得销账——沿旧·销账唯 COS）。
2. **跨面流转正形**：R 面执行毕报经 **BOD 各 COS 流转**回 M 面树（org-flow 现役：转发即域定·域内整班组独立闭环）——不跨面直投。
3. **供料端交接正形**：毕报落树+销账附指针后→排工席（供料端）验毕锚→树闭环；销账权/分派权/升级权边界沿 ⑦ 权界（排程建议单对 COS 无强制力）。
4. **窗毕件回声**：窗毕读数段入毕报（D1 窗毕型）+白名单登记面窗行刷毕态——窗轨回声多一面读数（直跑轨无此面）。
5. **C 面沉淀终点沿旧**：三个面做的每件事最后都沉淀回 C 面（CEO 00:05 立规原文不动）。
