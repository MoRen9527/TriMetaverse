## 三''·n 树粒度标准（COO 面定·BOD 收口项③）

**粒度四则**（拆 n 树时逐则对表）：
1. **独立可验收**：单树单验收锚·可独立判毕（验收判据入树面·沿台账筛选判据）。
2. **单一 owner**：单树单值席（不跨席·跨席工作包拆两树）。
3. **工时上界**：单树≤服务域值席段上界（试行 2h·候 CTO 对表校准）。
4. **依赖显式**：树间依赖在任务书面显式声明（依赖图）·禁隐含顺序。

**n 值边界**：n=1 合法（平凡件退化单树）；n 无硬上限·**n>5 时任务书应评估拆任务书**（级联候选·总调度建议权·拆分裁决归 COS 备料面）。

**拆树时点**：执行域拾取三校验过后·拆 n 清单（树表）挂任务书面·总调度复核后才进值席流水线——拆树权=执行域（Q7 定调）·复核权=总调度。
