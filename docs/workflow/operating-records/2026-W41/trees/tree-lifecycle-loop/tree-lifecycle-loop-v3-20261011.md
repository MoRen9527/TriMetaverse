## §二 探测面：树节点停滞被动探测（判据本体保留·角色归属勘正）

- 本席（COO）位置=专业 owner（§2 表）：①名下在管树的停滞读数**呈报**持树席（收编毕报时顺手·「建议下一节点」义务同构面）；②拆派节点（§8 节点3）收到持树席催办照 §8.3 响应；③不握分派权/升级权/销账权不变（09-11 ⑦ 权界沿用）。

### 2.3 停滞判据（三层+D-23 轨段阈值·v2 保留）

- **L1 树级**：树目录最后 commit 时戳超阈 且 树状态非终态 →停滞候选。
- **L2 节点级**：节点最后推进超阈 且 无有效「候」标注 →停滞候选。
- **L3 台账级**：沿用既有跨周平移线（4 周预警/8 周入催办面）——不另建。

| 时段 | 阈值 | 理由 |
|---|---|---|
| GLM/DS 黄金段（18:00→次日 14:00·DS 轨按价目实查回填） | 2.5h | 节拍密·滞后容忍低 |
| 平价段/人工辅面（9:00-12:00） | 4h | 默认档 |
| 禁排区（工作日 14:00-18:00） | 6h | 合法静默区·不误报 |
| 周末/节律拍点间隙 | 照各树承诺下一拍 | 见 2.4b |

### 2.4 挂起≠停滞（三区分·v2 保留）

- **a. 合法挂起**：「候+对象+时点」标注→不催。挂起标注必须引用候对象现势时点——X 过点即自动转催（催对象=候的持有方）。标注有时效：候对象现势变（如窗位勘正）→挂起标注随窗位复核。
- **b. 周期间歇**：巡检类/日更类对照承诺下一拍点，超 1.5 拍点间隔才算停滞（单时戳旧≠停滞·调度面承诺拍才是活性真值——LG-066 教训同构）。
- **c. 长窗在窗**：窗令硬锚未到→不催；超硬锚即催（§8.3「超窗即报」纪律同构）。
- 挂起超 24h 未解→升级挂起超时催办（候对象方责任面·持树席升级建议权）。

### 2.5 探测时机与催办出口（角色勘正改写）

- **时机（被动挂靠·三项）**：①持树席流转/汇录节点动作时顺手扫在管树；②专业 owner 收编毕报呈报读数时（本席例行面）；③候窗落 8713 cron 自动化（bod-tick 同拍或独立半日拍·挂账候办条）。
- **催办阶梯**：停滞候选→持树席对节点责任席催办（§8.3 接管证据正形+停滞形态 30min 一催·再 30min 升级建议呈 BOD）→回「在工」或「挂起」→挂起转挂起台账候其对象。（BOD 14:23 裁词点名顺手清「/COS 副本」三字——持树席即 COS 自己抄自己系 v2 残留笔误·COS 联署时清·14:36 落）
- **权界**：探测权/催办权/督办读数=持树席（COS）；升级建议权=持树席呈 BOD；台账销账变更权唯 COS 本职（§8 节点5-6 正形）；本席=专业 owner 呈报+拆派响应，不越权。
