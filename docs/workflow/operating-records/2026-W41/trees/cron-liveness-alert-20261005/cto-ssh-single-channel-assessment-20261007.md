## 评估结论：观察项成立；定性=**观测性单点，非可用性单点**；处置=候维护波低成本半冗余，现役不动

### 风险模型（为什么不是缺陷）

1. ssh 通道在盯梢链承担两职：互备对章（探测读数）+告警 hop（送信）——ssh 断=「看不见+报不出」双盲，成立。
2. 但被监视 daemon（TriMLC/TriMMC）**运行不依赖 ssh**——ssh 断时 daemon 照常跑，业务无损。单通道断损失的是观测能力，不是服务能力：**观测性单点≠可用性单点**，BOD「非缺陷」定性本席认账。
3. 后果分级：daemon 活+ssh 断=双盲但业务无损（高概率×低损）；daemon 死+ssh 断=盲+损（低概率×高损）。且现役有被动盲区信号：l2 探针失败留 l2-failcount 痕（连续上涨=通道疑断），只是无人消费该信号。
