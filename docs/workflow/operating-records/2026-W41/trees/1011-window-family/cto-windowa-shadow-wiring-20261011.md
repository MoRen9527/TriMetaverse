3. **三态语义**：
   - `AUTOMATION-READY（建议值）`——三查全 PASS；**仅建议值，机先判人后签，签挂位=COS**。

4. **签挂行**：COS 签挂后回写一行于判读 JSON 旁（`signedBy/signedAt/verdict` 三键）或原件准入标记行——终态以签挂为准，机器建议值永不自动生效。
