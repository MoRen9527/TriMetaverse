## 三、跳过与止损细则

- **跳过**：值席中/在途任务（自报或 transcript 活跃）/写作在途未 commit→登记，空闲即补，24h 内补毕；未补毕升级知会 BOD。
- **单席复活失败**：照 local-seat-relaunch SOP 排查（环境变量/剪贴板粘贴键入法），单席失败不停窗。
- **连续 2 席失败=停窗**：未重启席不动，保现势，候人工；已重启席不回滚（已复活席保持新态）。
- **迁移晚点**：重启窗整体顺延等待，00:15 硬止损——超时未开的本机剩余批+sg 批全数顺延周一晚，不抢跑。
