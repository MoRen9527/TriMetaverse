## 5.4 升级与回滚

**缺陷发现**：install-tricade.ps1 无版本比较逻辑（"同版本不覆盖"未实现，无条件覆盖）。

**实现**（install-tricade.ps1）：
- `Get-InstalledVersion`：ARP 优先（MSI 部署权威，现役 26.08.05.1）→ version.json → package.json
- `Compare-Version`：多段数字比较（支持三段 semver + 四段 calver）
- `Invoke-VersionGate`：同版本 → exit 2 拦截（`-Force` 强制）；新版本 → 升级放行；旧版本 → 降级（回滚）警告放行 + 现役备份 trilc.bak-*
- `Extract-Version` 支持四段 calver；`Test-Admin` 对 `-WhatIf` 豁免（干跑不要求管理员）

**WhatIf 三场演练（真实产物，全部通过）**：
| 演练 | 目标版本 | 现役 | 结果 |
| --- | --- | --- | --- |
| 同版本拦截 | 26.08.05.1（产物改名副本） | ARP 26.08.05.1 | 拦截提示（除非 -Force）✓ |
| 升级 | 27.08.13.1 | 26.08.05.1 | "升级：现役 26.08.05.1 → 27.08.13.1" ✓ |
| 降级回滚 | 0.4.2（v0.4.2-r12 产物） | 26.08.05.1 | 警告 + 备份后继续 ✓ |

**回滚预案**（可执行）：ZIP 安装前自动备份现役 `trilc.bak-yyyyMMdd-HHmmss`；回滚 = 停 daemon → 现役改名 → .bak 还原 → 重启 daemon（脚本既有机制 + 降级门禁放行）。

## BUG 处置声明（补充，2026-08-13）

### BUG-20260805-002（安装版 healthz version 未随构建更新）——**已修**

- 根因链（实测）：① build-desktop.ps1 F1-fix 写死 `version=1.0.0`；② PowerShell 5.1 `Set-Content -Encoding UTF8` 写 BOM → TriLC `JSON.parse` 对 BOM 抛错 → resolveVersion fallback `'1.0.0'`——写死值与 fallback 值相同，掩盖了解析失败
- 修复（双端）：
  - TriMetaverse `build-desktop.ps1`：version.json 改为注入 `-Version` 参数提取的构建版本 + `[System.IO.File]::WriteAllText` UTF8 无 BOM
  - TriMetaverse `build-tricade.yml`：assemble 注入 `$env:VERSION`（CI calver）替代复制源码 version.json（runner pwsh 7 无 BOM 问题）
  - TriLC `src/config/env.ts` resolveVersion：BOM strip 防御（旧 BOM 文件容错）
- **实测验证**：v0.4.3-r12 产物 version.json = `{"version":"0.4.3"}`（hexdump 确认无 BOM，`7b` 开头）；安装态临时 daemon healthz 返回 `"version":"0.4.3"`（此前恒 1.0.0）
- Commit：TriLC `c6b635d`（env.ts BOM 容错）；TriMetaverse（build-desktop.ps1 + build-tricade.yml 收尾 commit）
