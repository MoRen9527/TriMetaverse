## 5.4 升级与回滚

**缺陷发现**：install-tricade.ps1 无版本比较逻辑（"同版本不覆盖"未实现，无条件覆盖）。

**实现**（install-tricade.ps1）：
- `Get-InstalledVersion`：ARP 优先（MSI 部署权威，现役 26.08.05.1）→ version.json → package.json
- `Compare-Version`：多段数字比较（支持三段 semver + 四段 calver）
- `Invoke-VersionGate`：同版本 → exit 2 拦截（`-Force` 强制）；新版本 → 升级放行；旧版本 → 降级（回滚）警告放行 + 现役备份 trilc.bak-*
- `Extract-Version` 支持四段 calver；`Test-Admin` 对 `-WhatIf` 豁免（干跑不要求管理员）

**WhatIf 三场演练（真实产物，全部通过）**：
| 演练 | 目标版本 | 现役 | 结果 |
| --- | --- | --- | --- |
| 同版本拦截 | 26.08.05.1（产物改名副本） | ARP 26.08.05.1 | 拦截提示（除非 -Force）✓ |
| 升级 | 27.08.13.1 | 26.08.05.1 | "升级：现役 26.08.05.1 → 27.08.13.1" ✓ |
| 降级回滚 | 0.4.2（v0.4.2-r12 产物） | 26.08.05.1 | 警告 + 备份后继续 ✓ |

**回滚预案**（可执行）：ZIP 安装前自动备份现役 `trilc.bak-yyyyMMdd-HHmmss`；回滚 = 停 daemon → 现役改名 → .bak 还原 → 重启 daemon（脚本既有机制 + 降级门禁放行）。
