## 二·三候裁点意见

### 1. 节律：随现有 30min 拍·认（否独立低频拍）

- 收口时效敏感度高于 2h 档（终态卷落树→销账窗口本该小时级）；成本 <1min/拍 可忽略；独立低频拍=新节律新维护面，违「不新开 job」精神。

### 2. 阈值 4h：v1 统一 4h 采样·但**候窗族 v1 即差异化（实质意见·今日实例支撑）**

- **候窗族判据=窗位起点锚，非挂起时长锚**：挂「候窗令/候窗」行在窗起前属合法等待——挂起 >4h 不该催；正形=**窗起时点后 >4h 未动才催**（窗位锚取行内窗位或台账 windows 段对表）。
