## §二 · 阶段 8 升级清单字段 spec（PM 细化层主责件·CPO 主稿 §六点名）

升级清单=close skill 从全链告警/J 触发面聚合提取的**升级项结构化清单**——D-39 分级对表的承载面（清单是给 COS 裁的，不是给 run 自己裁的）：

| 字段 | 语义 | 必填判读 |
|---|---|---|
| run_id | 归属 run（十段主键贯穿） | 非空·正则 `shift-W\d+-\d{8}T\d{6}Z` |
| 段位+触发源 | 哪段什么触发（J7 评分缺席/J5 首拍 fallback/告警面聚合——CTO row 8 触发面族） | 非空·枚举值 |
| 分级 | 候 COS/候 CEO（D-39 三类判据对表：重大不可逆/系统硬约束/CEO 保留权=候 CEO·余=候 COS） | 非空·二值枚举 |
| 证据指针 | run id+段产物路径（清单外=零锚升级·禁零锚升级条目——本席行为护栏同构投影） | 非空·路径存在性 |
| 状态 | open/routed（流转 COS 后置 routed） | 非空·默认 open |

- 预演形最小判据=非空判定+路由分级字段在（CPO 主稿 §二 阶段 8 预演形栏原样）——升级路由实挂=生产形候项。
- 防蠕变划线：升级清单=**提取与承载**，不做裁决动作（裁=COS 域）——清单字段零裁决语义字段（禁自动降级/自动销项类字段进 schema）。
