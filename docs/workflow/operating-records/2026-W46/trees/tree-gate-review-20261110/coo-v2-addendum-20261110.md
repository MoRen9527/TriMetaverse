## §一 · duty-cos 退回+通知链工序细化（v2 §二-3 一句骨架→工序五步）

1. **闸 fail 判定落痕**：挂载脚本读授权件不过→树标 `rejected`+退回原因（缺授权件/字段缺失/status≠authorized/过期四类枚举）记挂载日志——退回原因枚举化=重挂勘正有靶。
2. **退回动作**：duty-cos 退回树包裹至本地域交单位（原路退回·不销毁不代改——代改越域）。
3. **通知路由**：本地域 COS（交单方·主通知）+BOD 知情（抄送）；**分级=P2 常态拦截**（闸职责是拦·退回非事故）——P1 留给闸失效/绕过企图（闸本身故障或检测到绕闸执行=事故级即报）。
4. **重挂闭环**：本地域勘正授权件后重挂走闸（同闸同判）——退回不罚（对事不对人）；**故意绕闸**（不经挂载的执行企图）归纪律册追责面——拦与罚两分。
5. **督办面接入**：退回件入本席督办读数单——观察期读数+1=**退回-重挂闭环时延**（拦截命中率/误报率之外第三读数·退回多=本地域授权件质量信号·时延长=工序堵点信号）。
