## 〇、分辨判据（先立尺，后逐环节）

**换实例测试法**：设想同一件用于另一 FADE 实例（如 FADE-006 执行面实例）——
- **原样可用**（不改一字照跑）→ **通用机制骨架**（归 fade-protocol-spec 协议层，一套复用，协议维护链管辖）；
- **须改内容才可用**（结构不动、换判据/换问题/换断言）→ **实例个性化件**（归实例 registry 条目+实例树，每实例自携）；
- **须改结构才可用** → 骨架设计缺陷（回协议层补骨架，不属两态任一）。

## 三、归属治理（骨架/个性化件各归谁管）

- **通用骨架**→fade-protocol-spec 正身层（协议维护链管辖；每次新增骨架=协议升版走维护链）；
- **实例个性化件**→fade-registry 各实例条目+实例树（registry owner 管辖；换实例=换配置不换骨架）；
- **判定规则**（〇节换实例测试法）入协议层作为**分辨判据条款**（后续实例升档沿用，免再联审同类分辨）。
