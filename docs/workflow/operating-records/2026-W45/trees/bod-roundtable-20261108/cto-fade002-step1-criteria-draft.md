## 〇、三态总览（迹象定性·非责任定性）

| 态 | 一句话定义 | 机械层信号 | 语义层判读 | 升级钩子 |
|---|---|---|---|---|
| **S1 真产出** | 当日有节点收口落卷 | git log 当日非空提交·触及 operating-records | 卷面含收口语形（毕/闭/审签/四态词） | 无（健康态） |
| **S2 在途** | 树 open+有增量·无收口锚 | 树目录当日 diff 非空·无收口语形 | 子态分辨：施工中/等回音/疑似卡死 | 无（健康态·等回音子态照常） |
| **S3 无产出迹象** | 三源全零增量·持续两窗 | git log 空+树 diff 空+mailbox 零往返 | 与 S2「等回音」机械同形——语义层分辨 | **两窗持续→L4b 通报责任席** |

**定性边界（d4 勘正立论·全判据的宪法条款）**：三态是**迹象定性**（"有没有产出迹象"）非**责任定性**（"谁在偷懒"）——S3 只触发 L4b 通报（责任席自分辨等回音/卡死/真闲置）·watcher 永不直接终判「闲置」。

## 一、S1 真产出·可操作判据

**机械层（零 token·必满足全部三条）**：
- M1.1：当日 git log（dev 分支·--since 当日 00:00+08）存在非 merge 提交；
- M1.2：提交触及路径含 `docs/workflow/operating-records/`（树卷/台账/周记录任一）；
- M1.3：非纯机械迁移形——排除路径白名单=仅触 `.shift-ade.json`/tick-log/自动巡检产物（自动件不算产出·防「机械迁移提交冒充产出」——值面三查纪律投影）。

**语义层（AI 读卷·确认任一）**：
- 卷面含收口语形：毕/闭/收口/APPROVE/审签/readiness 四态词（pass/retry/escalated/skip）；
- 或台账（LG 系/timer-tasks-ledger）当日有销项/入账动作；
- 或新周平面/新树/新正身文档落卷（create 形）。

**反例（判 S1 失败）**：commit 只触 runtime 代码无卷面（工程产出≠盯守语义面的"产出"——本判据只管盯守面·工程产出另线）；rebase/merge 空转提交。

## 二、S2 在途·可操作判据

**机械层**：当日树目录（operating-records 当周 trees/）有 diff 增量·但 S1 三条机械判据未全过。

**语义层·三子态分辨（AI 读卷判读）**：
- **S2a 施工中**：增量卷面呈推进形（brief 展开/读数落卷/审签征集中）——树 open+当日在写。
- **S2b 等回音**：当日有外发动作记录（SendMessage msg_id/派工单/催办）·尚无对端回执——**「已发≠在链」纪律投影**：S2b 判定须验外发记录真值（msg_id 在案）非自述「已发」。
- **S2c 疑似卡死**：无增量+无外发+无回执·但有 open 树+在办任务——机械面与 S2b/S3 同形·唯语义层可分辨——**疑似≠定性**：S2c 唯一动作=并入 S3 钩子（L4b 通报后由责任席自分辨·watcher 不代判）。

## 三、S3 无产出迹象·可操作判据

**机械层（三源全零·必满足）**：
- git log 当日零非 merge 提交；
- 树目录当日零 diff；
- mailbox/notify 面当日零往返（外发与回执双向零）。

**持续窗门（防抖确认窗纪律投影·禁单点定性）**：S3 终判须**两个连续读卷窗维持全零**——P1 每日窗形=当日全零+前日全零；单窗全零=瞬态（记观察·不作 S3 终判·不触发 L4b）。

**升级钩子**：S3 终判→L4b 通报责任席（名址=席组三元组·值席 COS 扇出）→30 分钟无回执→L4c 经 COS 链升级。

## 四、判定流程（P1 每日窗·两段式）

1. **机械段（零 token·tick 底座可内嵌）**：三源增量快筛→全零=候选 S3（进持续窗门）·非零=进语义段。
2. **语义段（AI 读卷·每日一次）**：读增量卷面→按 §一/§二判据归 S1/S2（含子态）→输出三态卷（watcher-daily-summary·逐态证据引用=卷锚+行锚·禁无锚定性）。
3. **产出**：三态卷落当日 operating-records 树·S3 终判走 L4b·S2c 候选并入 L4b 通报语。
