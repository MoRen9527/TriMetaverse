## §二 · 选型裁定（本席裁量·候圆桌追认）

**主选（b）=单一制度正身件**：`docs/workflow/weekly-plane-file-standard.md`——常设件清单正身（文件名模板+owner+生成机制+生命周期+周迁移行为逐行一物一行一 owner）·评审过经 COS 对表后落位·registry（company-governance-state.md）挂指针行随铸。

## §三 · 常设件分类学（初稿四类）

1. **常设周件**（带周缀·随周平移换缀续写）：scoring-ledger-w<WW> / cfo-quota-daily-w<WW> / project-*-weekly-<week> 类。
2. **常设跨周件**（无周缀·驻留原地续写）：company-demand-pool.md / daily-progress.md / weekly-plane-shift-runbook.md。
3. **滚动指针件**（-latest·生成机制覆盖）：fade-audit-latest / cos-decision-audit-latest——真源=时序卷（命名规则 R4）。
4. **事件卷件**（一次性·trees/ 归宿·禁落根）：task-inventory-* / handoff-* / 树卷毕报卷——task-inventory/handoff 现落根=历史遗留·新事件卷一律入 trees/。

## §四 · 防零散垃圾核心条款（初稿）

1. **入册门**：周平面根新增常设件须过正身件增补行（CAO 入册窗·一物一行一 owner+机制+迁移行为四要素齐方可入）——无行不落根。
2. **随手产物归宿**：随手一次性产物一律 `trees/<slug>-<YYYYMMDD>/`·禁落周平面根（树域=一次性域·根=常设域·两域分野）。
3. **弃用即销形**：常设件停用=正身件该行标注退役（退役件归档不删除·根目录不留尸——handoff closed 件候下窗归档 trees/ 或 archive/）。
4. **机器面挂接**：迁移器换缀/续写行为逐件对应正身件行——迁移器只认清单行·禁软编码文件名（联产出② P2 池系标准件族）。
