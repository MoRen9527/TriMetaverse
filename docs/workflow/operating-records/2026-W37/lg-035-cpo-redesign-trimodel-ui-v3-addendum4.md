### 2.1 子栏三新信息架构

```
模型切换策略 （以下策略应用于 TriMMC (sg)）      ←归属标注保留（增补件3§3）

     语义副注一行：「时间窗内优先用窗口模型；窗外用默认模型」
```

### 2.2 语义定稿（组合制，替代压制制）

- **默认模型**=兜底：无匹配时间窗时服务（原「固定使用」重构，措辞与心智双换）。
- **时段规则**=窗口内覆盖默认：窗内窗口模型优先，窗外回默认——**无冲突态**，两件规则自然组合。
- **增补件 3 §2.2「固定生效中时段规则不参与」提示条废止**（压制语义不再存在，困惑源连根拔除）。
- 时段规则**时间窗重叠=MVP 拒绝**，文案「时间窗与现有规则重叠，请调整」——确定性裁决，不引入引擎优先级隐式解析（引擎双向优先级保留内部机制，UI 零优先级控件）。
- start≥end 拒绝、HH:MM 校验、时区副注照增补件 3 §2.3 不变。

### 2.3 实现注记（CTO）

「默认模型」的引擎映射=CTO 确认项：现引擎 fixed=恒匹配压时段，与「兜底」语义相反——默认模型须以「最低优先级恒在规则」或引擎默认回落机制承载，**不得复用 fixed 压制路径**（否则组合语义被引擎静默改回压制语义）。产品语义只有一句：**窗内窗口赢，窗外默认赢**。
