## 〇、概念定稿（一句话）

**三实体=模型集／规则／策略＋引用关系**：模型集=勾选条目的命名分组；规则=自足的命名规则单元（时间/默认/额度三型）；策略={名，目的，引用模型集，引用规则[]} 的命名组合——同一模型集可被多策略引用、同一规则可被多策略引用。

## 一、三实体信息架构与交互

TriMMC 卡内五区：机器信息／模型信息（均不变）／**模型集**（新）／**规则**（新，外框与模型集同级）／**策略**。

### 模型集卡（模型信息同级）
- 集列表：集名｜集内条目 chips｜条目数｜操作（编辑/删除）
- 新建/编辑：集名（卡内唯一）+ 条目勾选列表（源=模型信息条目，多选）
- 删除守卫：被策略引用禁删——「该模型集正被策略引用，请先解除引用」
- 引用语义：条目引用指向模型信息已有条目（5b 引用式不变）；条目删除守卫扩展=被集引用同样禁删（「请先从模型集移除」）

### 规则卡（外框与模型集同级）
- 规则列表：规则名｜类型徽标（时间/默认/额度）｜摘要（窗口/条目/序列）｜启用开关｜操作
- 三类型表单（新建先选类型）：
  - **时间规则**：规则名+时间窗（HH:MM–HH:MM，校验照旧）+条目引用（下拉=已启用条目）——窗内用它
  - **默认规则**：规则名+条目引用——其余时段用它（增补件 4「默认模型」升格为规则类型）
  - **额度规则**：规则名+监控条目引用+转入序列（条目引用有序多选）——监控条目额度用尽→依序转入（§三）
- 删除守卫：被策略引用禁删；启用开关行内（停用=规则保留但不参与组合）
- 校验继承：start≥end 拒绝、重叠拒绝（同型时间规则间）、HH:MM 格式

### 策略卡
- 当前策略下拉（唯一活动指针，见 §二）+ 活动策略详情（策略名｜目的｜引用模型集｜引用规则列表，全只读）
- 新建/编辑策略=**纯引用组合**：策略名（唯一）+策略目的（可选，5b 沿用）+模型集下拉（单选，非选条目）+规则多选（下拉列表勾选）
- 删除守卫：活动策略禁删（「当前策略使用中，请先切换」照旧）；全删=「未启用」合法
- **组合复用承诺（走查断言级）**：同一规则被两策略引用时，编辑该规则→两策略详情同步变化（引用非拷贝的可见证明）

## 二、裁决：「当前策略 vs 活动策略」合并（CEO 质询③）

**合并定谳：单一概念「活动策略」。** 两词本是同一状态的控制面与状态面，双词并存=族 2 命名混乱残留，CEO 直觉正确。落地：①全 UI 只用「活动策略」一词，「当前策略」退役入禁用词表；②活动指针=策略区唯一选择器（下拉或行内「设为活动」），活动策略带「活动中」徽标；③可空=「未启用」（系统默认直通，语义不变）。

## 三、额度规则产品定义（CEO 点名进 MVP）

- 字段：规则名+监控条目+转入序列（有序条目引用，≥1）。
- 触发语义：监控条目 key 额度用尽→当前生效切至序列首个可用条目，依序下探；序列耗尽→停留+失败态提示「额度规则序列已用尽」。
- **数据源与判定归 CTO**：usage 基座已在 CTO 侧；「用尽」判定信号（配额/余额/阈值）由基座定义，**MVP UI 不暴露阈值编辑**——UI 只配「监控谁+转去哪」，判定透明委托。
- 诚实显示：额度信号未就绪时规则徽标「待额度数据」（不伪造生效）——冷边界纪律同族；触发历史入状态回写（COS 应用链回写照旧）。
- 计算位（活动策略域内）：额度触发=异常路径优先于常规；常规序=时间窗内窗口赢→窗外默认规则赢→系统默认（增补件 4 组合语义在活动策略域内保留）。

## 四、MVP 划线修订

- **进 MVP**：三实体 CRUD+引用关系+活动策略切换+额度规则（基础判定，CTO usage 基座接线）+boot 迁移+引用守卫族。
- **P2**：复制（策略/模型集/规则）、跨卡导入导出、额度阈值 UI 编辑、规则优先级显式控件、策略库高级管理、时间规则跨午夜。
- **销项**：增补件 4「可切换模型 chips」（模型集卡取代其职能）；5/5b 策略内嵌 rules/default_model 字段（升格实体引用）。

## 五、增补件 5/5b 继承与废弃边界

- **继承**：策略目的字段（5b）；策略名唯一/活动策略禁删/未启用态；三层计算序框架（域内扩为额度→时间→默认→系统默认）；S4 应用链按卡节奏；四卡作用域（trimmc: 前缀扩三实体共享）；boot 迁移思路（旧卡打包「当前配置」策略+「当前模型集」并置活动）；规则编辑器控件/校验/文案（降级为规则卡表单复用）。
- **废弃**：策略内嵌 rules 数组与 default_model 字段（升格实体引用）；「可切换模型」chips；「当前策略」双词。
- 文案终稿件：实体名相关行随本件重写，错误文案/校验文案/应用链文案继续有效。

## 六、数据形态预告（供 CTO 终稿）

```
card.model_sets:  { <msid>: { name, entry_ids: [] } }
card.rules:       { <rid>:  { name, type: 'time'|'default'|'quota', enabled,
                              time?: {start,end}, entry_id?, watch_entry_id?, fallback_ids: [] } }
card.strategies:  { <pid>:  { name, purpose?, model_set_id, rule_ids: [] } }
card.active_strategy_id: <pid>|null
```
引擎映射：活动策略展开——默认规则→default 层；时间规则→window schedules；额度规则→额度联动层（usage 基座）；模型集=宣告+额度缺省池。boot 迁移：旧 default_model→默认规则、旧时间规则→时间规则实体、条目组→「当前模型集」，打包「当前配置」策略置活动（幂等）。
