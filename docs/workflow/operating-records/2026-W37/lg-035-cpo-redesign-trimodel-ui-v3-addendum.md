## 补强① 连接设置区准入语义（一句话定稿）

**连接设置默认折叠；本机无已存令牌时首次加载自动展开一次，显示引导「首次使用：请填入 API 令牌与管理令牌（向管理员获取），填完点刷新」；已存令牌则保持折叠，页头仅显示「● 已连接」状态点。** 不做弹窗、不做每次提醒、不做多用户权限分级（令牌=本机操作者凭据，无多用户概念）。

## 补强② 两语义分区视觉归属（极轻量，图标+色系+一句副注，零术语）

- **TriMMC 信息主卡**：实线边框+远端标记（云形图标），卡头副注小字「保存后待应用」。
- **本机策略面折叠区**：灰调边框+本机标记（显示器图标），折叠标题副注「本机改动即时生效」。
- 判据：CEO 不展开折叠区也能从视觉分辨「上面这张卡≠这台机器的操作台」；两副注文案即语义归属全部，禁止再加术语解释。
