## 〇、概念定稿（一句话）

**策略 = {命名, 针对一个或多个模型, 规则组合} 的命名实体；卡 = 策略库 + 当前策略指针；切换 = 选策略名。**
示例：策略「白天生产」（默认 GLM-5.3；规则 14:00–18:00 用 deepseek-v4-pro）／策略「夜间省费」（默认 deepseek-flash，无规则=全时段）。涉模型集=规则引用模型的去重集，自动派生不另配。

## 一、策略实体信息架构

实体字段：**策略名**（卡内唯一，人读）＋**默认模型**（可空=回落系统默认）＋**时段规则数组**（每条=模型+时间窗+启用，复用增补件 4 编辑器与校验，作用域缩进策略内）。涉模型集与规则数=派生只读。

## 二、切换交互与应用语义

- 选策略（含「未启用」）→ 卡变更 → 按 **本卡节奏** 走应用链（TriMMC=待应用→COS 应用→已生效；本机卡=写入真源→轮询生效）——S4 语义统一在策略粒度不变。
- 切策略=**替换引擎生效规则集**：活动策略的时段规则+默认模型接管三层计算序（活动策略窗口命中→活动策略默认模型→系统默认）；「未启用」=系统默认直通。
- 同策略内编辑规则/默认 → 常规待应用，与切策略同链无特例。

## 三、策略管理交互

- **新建**：表单=策略名+默认模型+时段规则编辑（空规则+有默认=合法，即「全时段默认」策略，如「夜间省费」）。
- **编辑**：改名/换默认/增删改规则；活动策略可就地编辑（待应用链不变）。
- **删除**：仅编辑视图内；**活动策略禁删**，文案「当前策略使用中，请先切换到其他策略」；至少保留零策略合法（全删=回到「未启用」）。
- **MVP 划线（本席裁）**：进=新建/编辑/删除/切换+boot 迁移转写；P2=复制策略、跨卡策略导入导出（四卡形态下与跨卡 key 共享同包考虑）、策略库列表/排序/分组。

## 四、四卡作用域嵌套

- 策略=**卡内一等实体**，随卡作用域（trimmc: 前缀命名空间），不做全局策略池；跨卡复用走 P2 导入导出。
- 本机卡（TriRLC/TriMLC）策略同构，仅应用节奏不同——策略概念四卡通用，图例护栏（卡面=物理的镜子）不破。
- 「未启用」态与 TriRLC 卡「未配置」态同族：物理不存在的接管不伪造。
