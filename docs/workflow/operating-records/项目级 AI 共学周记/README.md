# 项目级 AI 共学周记归档

本目录用于归档已经由 CEO 确认签发的项目级 AI 共学周记，便于后续按周查阅、复盘和对外分享。

## 归档边界

- 每周工作草稿仍先落在 `../YYYY-Wnn/project-ai-community-weekly-YYYY-Wnn.md`。
- CEO 确认签发后，再把对应版本归档到本目录。
- 本目录只放签发版、索引和必要的归档说明，不承接当周持续编辑中的草稿。

## 版本规则

- 草稿阶段使用 `draft-YYYY-Wnn`。
- CEO 确认后生成正式版本号，建议使用 `vYYYY.Wnn.1`，例如 `v2026.W18.1`。
- 如果签发后仍需修订，按末位流水递增，例如 `v2026.W18.2`。

## 周期规则

- 每周开始由维护者创建当周草稿。
- 每次虚拟公司相关对话后，包括 CEO 与 agent、agent 与 agent 的对话，维护者都应判断是否有值得总结的大模型能力问题、体验或经验。
- 每个问题按当周文档第 2 节固定格式逐条追加。
- 周六 12:00 前必须完成一次分享会前更新，供周六 20:00 分享会使用。
- 每周结束前由维护者升级给 CEO 确认签发，并把签发版归档到本目录。

## 当前自动化状态

当前自动创建、自动追加、周六中午自动更新和周末签发提醒尚未实现。

在总助具备常驻与 cron 能力后，例如后续借助 `TriMC` 吸收简版 OpenClaw 能力形成 resident / cron 链路，应优先实现这些自动化。具体待实现功能见 [automation-backlog.md](automation-backlog.md)。
