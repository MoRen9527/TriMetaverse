## 面① · flag 四态闭环纪律（令③·状态机条款化）

**现状缺口**：回退条件现散落于口述令文（prod ≤95→test / test 8 轮未回>95→debug / debug 联审+CEO 融合 / CEO 可令 test / test >95→prod），无条款形态——状态名、转移条件、出口门、留痕义务均未条文化，跨轮执行靠记性。

**建议条款形（五款）**：

1. **四态定名与语义**：`prod`（生产·每周日正常迁移）/ `test`（试跑态·loop 内迭代）/ `debug`（故障态·候联审与融合）/ `CEO 认可位`（越态明示位·非状态是裁决动作）。四态互斥，同一时刻仅一态在役。
2. **转移条件机械可判**（全部数值/明示可判·禁体感）：
   - `prod --(轮评总分 ≤95)--> test`（自动触发·零人裁）；
   - `test --(轮评总分 >95)--> prod`（自动触发·零人裁）；
   - `test --(满 8 轮且最高分未回 >95)--> debug`（轮次计数硬约束·计数单位=完整一轮评审计）；
   - `debug --(7 席联审毕 + CEO 融合意见达)--> 下一轮 test`（**两条件缺一不出**·联审无 CEO 融合=不出 debug）；
   - `CEO 明示认可 --> 可令 test`（CEO 裁决位·D-39 三类保留权范畴·明示优先生效）。
3. **禁跳态与禁回改**：状态转移须逐态（prod↔test↔debug 不跳；CEO 明示除外）；已发生的转移记录禁 retroactive 改判——除 CEO 明示或本席勘误留痕双签。
4. **转移留痕义务**：每次转移必落卷——原态→新态+触发读数（分数/轮次/明示锚）+时点（D-47 正形）。无留痕的转移=未生效（状态面唯一证据=落卷）。
5. **prod 常态豁免**：prod 在役期间每周日正常迁移不受 loop 机制干预（loop 是 test/debug 面机制·不动 prod 排程）。

**引 D 系先例**：D-39（CEO 明示位属保留权域·不经代裁）+D-82（连续推进·不设人为门距）+D-83 款1（集中施工承载位）。

## 面② · 百分制口径纪律（令⑥·评分暴露面）

**现状实勘**：现役 score 卷为 `scores{I1,I2,I3}` 档位制（0-3 档），聚合卷另有 caps→百分比映射（aggregate-final 载 seven_seat_average=80.0/threshold=95）——**两套口径并存**，且 CEO 令明示「现两席 I1/I2/I3 读数非百分制=错」。

**建议条款形（五款）**：

1. **单一主口径=100 制**：每席每轮产出**单一总分 0-100**（席面主读数）；I1/I2/I3（或十项）降为 **breakdown 分项**（供复核溯源），**聚合与门判定唯用总分**——禁以分项档位充当席面分。
2. **七席同口径**：维度定义/权重/阈值七席共用一套（同一评分细则卷）——禁「两席一套、五席另一套」；口径变更须在轮次边界一次改齐并留痕。
3. **聚合暴露形**：`per_seat_total_100[]`（七席全列不藏）+`seven_seat_average`+`threshold`+`verdict` 四件齐（现 aggregate-final 已具后三件·补「per_seat 全列缺一即聚合无效」）。
4. **拒判与缺项禁折算遮掩（令⑤条款化）**：维面拒判/缺项**不得以折算/加权/补位方式并入总分**遮掩——正形=该维显式标 `rejected`/`N-A` 并计 0 分或按细则明确的最不利值，同时**在评分卷暴露拒判理由**（走评审提改进）。**违例先例=CTO 59/59 折算案**（把判据缺陷折算成满分）=本条首案。
5. **分数变动可观测（令⑧）**：每轮聚合卷必载「与上轮分差表」（逐席 Δ+总分 Δ）；**零变动轮次=自动在评审卷标注「循环无意义告警」**（评审须 catch·见面③款4）。

**引 D 系先例**：D-46（暴露面纪律族·值面禁遮掩同族精神）+D-15（联审门·评审双席制）。

## 面③ · 意见带入下轮机制（令⑦·评审 catch 义务）

**现状实勘**：`improvement_opinions[]`（topic/rationale/evidence_ref/check_time）与 `improvement_aggregation.topics` 聚合形已在——但**无「上轮意见→本轮处置」回填面**；跨轮意见是否被采纳/为何未采纳，卷面无载。故「意见未带入下轮=评审也未 catch」为现势真实缺口。

**建议条款形（四款）**：

1. **意见回填表强制**：每轮评审卷必含「上轮意见回填表」——逐条列上轮 `improvement_opinions` → 本轮处置态∈{采纳, 部分采纳, 未采纳} + 理由 + 证据锚（改动 commit/卷位）。
2. **条数守恒机械可判**：上轮意见条数 N ⇒ 回填表条数 **=N**（漏一即缺陷·机械可判）；该条为评审卷完整性门（缺回填表=卷不合格·不受理聚合）。
3. **意见跨轮台账**：意见不因换轮消失——累计台账（意见 ID·首提轮次·各轮处置态序列）；聚合卷 topic 分组保留（现状形承）。
4. **评审 catch 三义务（令⑤⑦⑧合成款）**：评审机制每轮须主动 catch 三事——①**分数无变动**（面②款5 告警）②**意见未带入**（本条款2 条数守恒）③**拒判被折算**（面②款4 违例形）。**catch 失职=评审本身记缺陷**（本轮评审评分扣面并载入回填表）——防「评审只打分不纠偏」。

**引 D 系先例**：D-17（发现即提族·catch 义务同族）+D-82 款3（违者处置三链·评审失职问责形）。
