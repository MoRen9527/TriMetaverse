## §二 · 召集段自动化主形：控制面值守循环自动化（§3.3 详案·先给结论）

**主形裁=召集段自动化跑在 m-duty-cos 值席会话的值守循环内**（非 daemon 机械面·非跨会话驱动基建）——召集件机械模板化+逐席派工+卷面巡检+recycle 调用+动作执行全在控制面会话内自动跑。理由三锚：
1. **r101 钉原样维持**：机械面禁自判=机械模块（recycle 等）禁 POST/touch·动作归控制面——v2 把控制面的动作自动化（控制面会话内循环执行 marker 序）≠动作归机械面·r101 字面与精神双零触·零修订零备案成本。
2. **零新基建**：SendMessage 直达（M-004 口径）+树面巡检+CLI 调用全为值席会话现役能力面——不建 daemon 席位投递端点（跨会话驱动基建=大工程·候远期面非本期）。
3. **值席退监督位语义吻合**（CEO 裁）：值席从人工编排者退为监督位=其会话自动循环执行·异常时人工介入（挂起处置/schema 失配/终签三触点见 §四）。

依赖代价如实列：**值席会话在线依赖**——值席挂=召集循环挂；降级=W1§四.1 挂起态语义本有（loop 照跑不阻塞·下轮 run 消费段兜底）·零新增风险面。

### 3.3 召集段自动化（主形详案）
值席值守循环新增「联审召集自动段」——触发条件=树面 trigger 件巡检命中 `convene_mode=auto`（或 notify 信）→自动执行：
1. **召集件读取**：run_dir 材料包指针+dim_b 初判卷位+落卷要求（契约面 §四模板化指令包机械预编排）。
2. **逐席派工**：SendMessage 直达七席（M-004 口径·模板化指令=材料指针+自评规约+落卷路径+preliminary 标注要求）——缺席席自动补召一次（超时挂起照 W1§四.1）。
3. **卷面巡检回收**：scores-root 七席卷巡检（机械清点 valid/absent/mismatch·schema 校验复用 recycle validate 面）。
4. **quorum 判定**：≥5/7→调 recycle CLI（`--threshold 70 --round N`）；<5→挂起态标注+补召+loop 照跑（不阻塞语义恒守）。
5. **verdict 动作执行**（§3.4）+树面留痕（每步落召集日志卷·时间线可审计）。

### 3.4 动作执行面——r101 边界原样维持
- recycle decide 六态判定**零改动**（纯判定·零 POST 零 touch——W2 施工钉不动）。
- verdict 动作=控制面（值席会话循环）自动执行：`loop_next`→marker 序（touch marker→POST /run·白名单单通道·X-Internal-Token 现役）自动发起下一轮+改进意见卷随触发件流转；`converge`→关 loop 动作+**终签护栏**（§3.5）+候 CEO 终认流转；`escalate_ruling`→转候裁面禁自主续转（自动挂候裁·禁续转语义零触）；`pending_*`→挂起态照走。
- **论证**：r101 定谳=机械面禁自判·动作归控制面——v2 全自动包到底=**控制面动作自动化**（控制面会话内自动执行其本有权执行的动作）·判定面仍机械·动作面仍控制面——**边界结构不变·只提速**。零修订零备案。

### 3.5 「自评初判只作前值不作分数」语义裁决（两案摆明·主裁建议案一）
- **案一（前值入分+终签护栏·主裁建议）**：dimA 前值入总分（100 制维持·threshold=70 双锚语义不动）·但 converge 终局须值席监督位**终签确认**（终签前=前值非终局分数·终签=人工确认点=「不作分数」防膨胀本义）；loop_next/escalate 路径前值照走零人工（全自动包到底在非终局路径成立）。
- **案二（前值纯材料面）**：dimA 前值不入分叉判定·总分=机判+dimB 两域（90 制）·threshold=70 须换算（70/100→63/90 等比）或重裁（COO 会签再来一轮·双锚刚裁毕即动=不稳）。
- **主裁建议=案一**：①threshold=70 双锚（7f6575934+9625290f9）刚裁毕生效·换制=重裁成本+裁决不稳期；②终签护栏满足防膨胀本义（自评永不自动终局·监督位一签兜底）；③CEO 两裁语义双贴（自动包到底零人工路径+前值终签前非分数）；④converge 本就候 CEO 终认——终签=终认链内自然一环非新增人工面。候 COS/CEO 备案采认。

## §四 · 自动化护栏与降级（fail-closed 三触点）

自动循环三个人工触点（护栏非瓶颈·每触点留痕）：
1. **dimB 复核转正**：机械初判 preliminary→值席复核转正（判据模板化后复核=抽验级轻量·异常才逐族勘）。
2. **converge 终签**：终局分确认一签（§3.5 案一）。
3. **挂起/失配处置**：pending_quorum 补召裁决·contract_mismatch 候勘面转 FSD 修件窗——自动循环对此二态=挂起标注+值守知会·处置人工（防线不放松语义）。

降级三支路承 W1§四（skip fail-closed/挂起 loop 照跑/schema 拒收）全保留·新增：**值席会话离线**=召集循环停摆→下轮 run 消费段兜底（trigger 件在树面在位·值席复活后巡检即续·零丢件零阻塞）。
