## §一 · 架构总形：三段解耦（触发→召集→回收）

**裁：loop（河源 TriRMC 无头自动化）与联审（七席会话面·跨机）=解耦-触发-回收三段形**——联审本体=会话面编排（七席有 soul 席·非 API agent·禁无头面造伪会话）·loop 面职责=触发件产出+评分消费+循环控制执行——接线正形=**文件信箱+通知双通道**（树面共享检出物理可达+notify API 通知面）。

| 段 | 执行面 | 形态 |
|---|---|---|
| 触发段 | TriRMC run 收口段（河源·loop 内） | fade-001 十阶段毕（manifest close pass+11 件齐）→产出 joint-review-trigger.json 落 run_dir/树+notify 通知 |
| 召集段 | m-duty-cos 回报收口（sg·会话面）→派工七席 | r128 第一收口职责·SendMessage 跨会话直达派工·七席各自作答两维度评分卷落树 |
| 回收段 | TriRMC 下轮 run 消费段（河源·loop 内） | 读评分卷（三卷形现役·collection-score 消费面 fsd-r119c 已对形就绪）→分数面判定→分叉 |

**禁走形态（如实钉）**：TriRMC 直接驱动七席会话（无头面无此能力）——召集段必经会话面中转（m-duty-cos=CEO 批令第六点回报路线第一站·职责天然对位）。

## §二 · 核心接线：七席召集机制（任务书点名难点·裁）

1. **触发件契约**（joint-review-trigger.json 最小字段形）：loop_run_id+run_dir 指针+两维度材料指针（维度 A=fade-001 实现度材料：manifest/score/plan 读数卷指针·维度 B=周平面迁移质量材料：counts/ar/unresolved diff/ops commit 指针）+三域分现读数+**分数线接口位**（线值面候 COO/CEO·本设计留参不代裁）+触发时点。
2. **召集链正形**：触发件落树→notify→m-duty-cos 收口拾取→按席单（七席=COS/COO/CAO/CPO/CTO/CHO/CFO·r129 材料）逐席派工→各席会话面作答→评分卷落树（沿现役三卷形契约·双卷并存形第 10 轮已实证）。
3. **两维度分列禁混打接线**（r106 形）：两维度=两份独立评分卷+各自 verdict_rule 对表（维度 A=subjective 试卷形 rubric-firstshoot 真源·维度 B=collection 试卷形 fsd-r119c 重采正形）——**两维度材料包/评分卷/回收面全分立**·禁并卷禁互判（与 A 族两基准禁互判同族纪律）。

## §三 · 联审触发点+循环控制（r101 定谳接线）

- **触发点**：fade-001 十阶段毕后发起（r101 定谳·不拆段·评整轮迁移质量·r88 异步形废止遵行）——落 manifest close 段 pass 后的收口段。
- **循环控制**：**分数面驱动·机械面禁自判**（r101 定谳钉死）——TriRMC 回收段读评分卷→三域分齐判定→分数不足→控制面按 marker 序正形（touch→POST·现役通道）发起下一轮 loop·联审改进意见卷=下一轮输入材料随触发件流转——分数达标→收敛段（关 loop 候 CEO 终认·r101 形）。
- **循环上界接口**：轮数上界参数位留（防无限循环）·值面候 COS/CEO 定（本设计留参·默认建议 3 轮未达标转候裁面·禁自主续转）。

## §四 · 失败降级形态（三支路）

1. **七席缺席/超时**：quorum 形——已有席评分照收+缺席席标注缺席态·quorum 线候选值=≥5/7 有效评分可判定（留参·候 COS 编排确认）·<quorum=触发件转挂起态（树面标注·候 m-duty-cos 编排补召）·**loop 照跑不阻塞**（联审与 loop 常规轮次解耦另一半：评分挂起仅挂收敛判定·不挂常规轮）。
2. **TriRMC 面失败**：fail-closed 照役（现役防线语义零扩面）——触发件产出失败=该轮联审不发起·如实报 m-duty-cos。
3. **评分卷契约失配**：回收段 fail-closed 拒收（零强判）·挂候勘面（FSD 修件窗走）——防线不放松。
