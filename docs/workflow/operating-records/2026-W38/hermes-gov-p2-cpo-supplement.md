## 一、接入段信任分级细节（三则操作化规则）

1. **保守默认档**：新入素材默认 **working**（非 confirmed）——confirmed 须第二证据：第二独立来源印证 / 收口席核 / 被消费一次且无纠错回流。自标 confirmed 无效（来源方自标≠确认）。
2. **来源路→默认档位映射表**（免逐条判断负担）：人工投喂=提交人定（draft/working）；会话产出=working；事件接入分两类——registry 快照/治理令=confirmed（已有收口核背书）、会议结论=working（待消化确认）。
3. **升档留痕**：working→confirmed 升档动作写 audit 一行（触发证据+操作者）；MVP **不做自动降档**（无消费压力数据，观察项留档）。

## 二、归并语义边界（四则）

1. **归并粒度=结论块**（块=结论+来源+时点），非整页重写——页面=结论块集合，provenance 块级可追。
2. **冲突规则**：新素材与页内既有结论矛盾→**不覆盖**：新块照常并入+页面整体降 working+escalate 人工裁——矛盾是页面降级信号，禁止静默改写既有结论。
3. **勘正语义**：错误结论不物理删——新块引用旧块标「已修正」，页内历史可追（历史冻结/真源可修口径的页内版）。
4. **页容量阈值**：单页结论块>20（对齐 maxSources=20 语义）→分裂候选 escalate 人工裁，不自动拆页。
