## 一、背景：CEO 重大架构纠偏（2026-08-16）

### CEO 原话

> "我们还让小乔和小狄分清楚：本地研发仓（claude code）+ 服务域 TriMC（套壳 claude code）+ 本地域 TriLC（自研）的架构协作，是**训练本地域 TriLC**，成熟以后源码替代 TriMC。TriMC（源码套壳）、TriLC（成熟源码），这样实现互为 fallback。这应该划归**训练期**。
>
> 我们现在的（上面的设计）舰队互为镜像，应该是**正式生产期**。
>
> 所以不应该混为一谈。而且 TriMC 和 TriLC 共同的核心是 agent-core——那就等于正式生产期 TriMC 直接使用 agent-core 就基本直接获取成熟源码能力了吧？训练器 TriMC 分叉没有走 agent-core，而是去驱动套壳 claude code。训练期是不需要服务域和本地域 agent 互为镜像，他俩是**审核和教练关系**；正式生产期才需要使用**同一上下文，同一时间只有一个 agent 生效，谁掉线另一个顶上**，才叫互为镜像吧。
>
> 小贾，整理所有思路和需求，让小狄和小乔重新整体评估两个阶段和方案功能设计，理清楚我们要干什么，怎么干，不要乱。"

## 二、两阶段划界（核心修正）

### 2.1 训练期（现在 —— ？）

**定义**：TriMC = 套壳 claude code 驱动舰队（不走 agent-core），TriLC = 自研 agent-core

**架构协作关系**：教练/审核关系（**非镜像非热备**）

**目的**：TriLC 训练成熟，能力沉淀进共同核心 agent-core

**关键特征**：
- TriMC 分叉：不走 agent-core，去驱动套壳 claude code
- TriLC 自研：基于 agent-core，能力成熟后下沉
- 两域关系：审核和教练关系（TriMC 审核 TriLC 输出，TriMC 教练 TriLC）
- **不互为镜像**：不同上下文，不同 agent 同时生效

**里程碑（何时算成熟 → 生产期触发条件）**：
- TriLC 能力清单收敛（具体指标待小狄定义）
- agent-core 能力下沉完成（哪些能力必须下沉）
- 呼应 M4 启动条件六条（待重新审视）

### 2.2 生产期（目标态）

**定义**：两侧同跑 agent-core

**架构协作关系**：互为镜像（同上下文、单活、掉线顶上 active-passive 热备）

**目的**：TriMC 直接获得成熟能力，真正互为 fallback

**关键特征**：
- TriMC 直接使用 agent-core → 基本直接获取成熟源码能力
- 同上下文：两域共享同一上下文
- 单活：同一时间只有一个 agent 生效
- 掉线顶上：active-passive 热备协议

**前提条件**：
- agent-core 双侧部署
- 能力沉淀完成（训练期成果）
- 热备协议实现

## 五、两阶段各自要干什么/怎么干

### 5.1 训练期（现在）

**目标**：TriLC 训练成熟，能力沉淀进 agent-core

**做什么**：
1. TriLC 能力清单收敛（按 checklist 逐项覆盖）
2. TriMC 审核 TriLC 输出（教练关系）
3. 能力下沉到 agent-core
4. 授权清单机制（TriMC 审核 TriLC 可推进的工作）

**怎么干**：
- M0-M4 里程碑（重新定义）
- TriLC 在 TriMC 监督下逐项覆盖（M2）
- 能力下沉路径（agent-core 共享包）
- 授权清单配置（本地授权服务器推进）

**不做什么**（生产期才做）：
- 双域双向同步
- 冲突解决规则
- 一致性校验面
- 热备协议

**里程碑（何时算成熟 → 生产期触发条件）**：
- TriLC 能力清单全勾
- agent-core 能力下沉完成
- M4 启动条件六条达成（待重新定义）

### 5.2 生产期（目标态）

**目标**：两侧同跑 agent-core，真正互为镜像

**做什么**：
1. agent-core 双侧部署
2. 热备协议实现（active-passive 切换）
3. 同上下文共享
4. 双域双向同步
5. 冲突解决规则
6. 一致性校验面

**怎么干**：
- TriMC 直接使用 agent-core（替代套壳 claude code）
- 热备协议实现（同上下文、单活、掉线顶上）
- 双向同步协议（sync-engine 扩展）
- 冲突检测与解决（三层检测）
- 一致性校验（HEAD/Applied/Session 三层）

**前提条件**：
- 训练期能力成熟
- agent-core 下沉完成
- M4 启动条件六条达成

## 八、评估结论（待小狄小乔确认后收口）

### 8.1 现在做什么（训练期）

**核心动作**：
1. TriLC 能力清单收敛（M2 持续）
2. 能力下沉到 agent-core
3. 授权清单机制（TriMC 审核）
4. 单域会话管理（reset、初始化）

**不做什么**（生产期才做）：
- 双域双向同步
- 冲突解决规则
- 一致性校验面
- 热备协议

### 8.2 不做什么（生产期才做）

**延期到生产期**：
- 双域舰队互为镜像（c83ffe80）
- Session 双向同步
- 冲突解决规则
- 一致性校验面
- 热备协议实现

### 8.3 怎么做（里程碑）

**训练期里程碑**：
- M2 能力验证期（持续）
- 能力下沉完成（触发条件之一）
- M4 启动条件六条（触发条件之二）

**生产期触发条件**：
- TriLC 能力清单全勾
- agent-core 下沉完成
- M4 启动条件六条达成
