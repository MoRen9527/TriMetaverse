## 一、总纲（两条，贯穿全件）

1. **消费模型=启动注入（非检索）** ⇒ 知识产物做「**注入页**」非搜索词条：结论前置/自包含/可整段用整段弃/体积预算。互链是检索范式产物，注入范式下「单独进上下文也成立」才是页面价值。
2. **吸收原则**：吸收「使体系更可靠/更省成本」的机制，不吸收「对外发布形态」（上游 hermes 对标的判定准则；不吸收清单见 §五）。

## 二、消化管道四段（产品语义）

```
①接入 → ②消化 → ③结构化输出 → ④wiki 对接 →（下游）升格通道 org/shared
```

### ① 接入（来源三路+信任分级+来源标注强制）
- 来源三路：会话产出（自然沉淀）/人工投喂（inbox 放料）/事件接入（会议、收口、治理令）。
- **信任分级**（用现成资产 inbox frontmatter trustLevel）：confirmed 直入消化；working 入但标注处理深度；draft 仅暂存候确认。
- **来源标注强制**：无源素材不可消化——溯源是注入可信度前提。

### ② 消化（消化者=agent 本席；schema=可执行判据）
- 消化者=**agent 本席**；schema 产品形态=给 agent 的**可执行判据**（含示例/反例），非机械匹配器。
- 动作链：**提炼**（事实+判断+待确认）→ **归并**（并入已有页为主、新建页为辅——「形成知识体系」=对号入座，非每次堆新页）→ **阀门三决定**（digest/reject/escalate——阀门属本段，非全貌）。
- 「体系」来源=page-specs 页面分类体系（由 memory.md 定义）。
- 咬合点（CTO）：digest-rules.yaml 声明式规则+daemon 消化器（shallow 零 LLM/deep 档 LLM）；触发=会话收口不在热路径。

### ③ 结构化输出（注入页四约束+两态+节律）
- 四约束：结论前置/自包含/可整段用整段弃/**体积预算**（注入=每会话固定 token 成本，bootstrap 已 47-48K 窗）。
- 两态：working（新吸收/消化中）/stable（稳定可依赖）——注入时分级处理。
- 溯源标注强制（每结论块带来源）；**「待确认」=诚实体内债务**：学习审计面不静默丢。
- 节律：会话结束=自然消化点；周度收口=批量点。
- 咬合点（CTO）：产物契约+async prefetch 骨架（异步消化→落页→下会话注入消费）。

### ④ wiki 对接（累计并入为主+幂等+升格通道）
- 对接对象=员工自己的 wiki（私域）；**累计并入为主**（页面是活的），新建页仅当体系内无归位处（防页面碎片化）。
- 吸收标记幂等：被消化 inbox 源须标记，防重复消化。
- 消费=启动注入；**下游升格通道** wiki→org/shared：**去域化检验**为唯一上行判据（脱离岗位语境还成立吗），人工门+provenance 留痕。
- 咬合点（CTO）：v2.0 三表零动+digest_log 增量。

## 三、知识分发三层（定稿）

| 层 | 内容 | 消费方式 | 成本 |
| --- | --- | --- | --- |
| **核心** | 全员必会 | 全量注入（org/shared 核心层） | 全席固定成本 |
| **可选** | 按岗位/按需 | 岗位装载 | 按岗成本 |
| **目录** | 想学但不在必读 | **可发现/不装载** | **零注入成本** |

- org/shared 单品判据：「不进会怎样？不怎样=不进」；写权=提案制+单一收口。
- 目录层承载建议=CGR 目录索引面（已转 CAO/CGR 侧候确认）。
- 机制对表（CTO 域）：page-specs 扩分发层字段。

## 四、管道质量基线三指标

1. **归并正确率**（抽检：素材归页是否符合体系分类）；
2. **注入页可用性**（抽 3 页去链可读——自包含断言）；
3. **reject/escalate 判定复现性**（同一素材二次消化判定一致——幂等+判据稳定性）。

## 五、不吸收清单（明文防扩范围）

apps/ 桌面化（治理体系）｜多语言化｜docs→website 迁移｜evals 完整框架｜可编程灵魂工程实现——均对外发布形态或上游规模件，内部自用体系不需。单列转记：上游 desktop 形态对 TriCade 产品线有对标价值（候令另件）。

## 六、验收锚（产品面）

①管道四段产品语义写入正身 ②三层分发落地（目录层零注入成本断言）③质量基线三指标可测 ④org/shared 分层可见+单品判据执行 ⑤注入页四约束断言（含去链可读）⑥不吸收清单原文随正身（防后续对标漂移）。
