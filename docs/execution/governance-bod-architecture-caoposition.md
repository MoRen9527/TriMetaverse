# BOD 架构走向——治理结构面立场件（CAO 主笔）

- sourceOfTruth: TriMetaverse/docs/execution/governance-bod-architecture-caoposition.md
- syncMode: draft｜lastSyncedAt: 2026-09-09
- 性质：治理架构级联审**立场稿候审**（CEO 亲定议题；CAO 治理结构主笔+CPO 业务演进/CTO 技术可行性同步征集中；合成后呈 CEO——候审不动真源不实施）
- 议题：「BOD 是只有一个？还是 M 面和 R 面各有一个 BOD？」——公司从一人+AI 工具向自主 AI 公司演进的最高治理层架构走向

## 一句话立场

**现役单 BOD 面（跨 M/R 统一）；双 BOD=档 3 条件触发预留（R 面独立经营责任成立+CEO 显式立法拆分方启动）；立即行动项=三类保留权清单成文（CAO 域自领）。**

## ① BOD 数量：单面现役，双面推迟而非否决

- **治理效率**：单 BOD=单一决议记录面/单一升级链终点/名址宪法单表（D-13 现行）。双 BOD 立即产生元治理问题——两决议冲突时谁终裁？答案只能是 CEO，于是 CEO 被拉回日常仲裁，违背设 BOD 让 CEO 低频化的初衷。
- **风险**：双面=决议分叉先例面（同一事项两面板决不同结论=治理分裂）；且 **R 面现役不构成独立治理对象**——治理跟着责任走：R 面=agent-core 学徒位（M 成熟一步教一步，CEO 定则），其产出验收归 M 面/CEO，无独立经营责任面即无独立 BOD 的治理标的。
- **双 BOD 的唯一真实收益**（R 面自治后本地决策低延迟）可用**单 BOD+授权清单扩容**替代（授权矩阵分层扩大 R 面自决域），成本远低于双面拆分。

## ② BOD 与 CEO 关系：权威代理（受托治理体），非工具

- 定性证据：BOD 有独立会话记忆/台账（board-journal）/纪要归档/批件序列（审批权限定则三例：密钥正身/D-23/D-24）——工具不记账不担责；BOD 记账+转呈错误自录更正=受托体特征。**BOD=CEO 的受托治理体（权威代理），保留权外日常治理的代行面。**
- 对数量决策的影响：权威代理定性→**代理权单源原则**——一个委托人（CEO）对一个受托面（BOD）。双 BOD=一份委托拆两份同权委托，「三类保留权始终升 CEO」将退化为「升哪个执行面」的操作歧义。②反过来锁死①的单面结论。

## ③ 两轴螺旋中的 BOD 演进：三档触发线（读数化，防感觉化）

- **档 1（现役）**：R=学徒位——单 BOD，R 面事项走升级链。
- **档 2（触发=R 面独立任务线≥2 且持续产出+R 面出现独立对外责任迹象）**：仍单 BOD，内设 **R 面常设席位/分委员会**（r- 席专责 R 面议程）——委员会制非分立制，保单一决议面。
- **档 3（触发=R 面独立经营责任成立〔对外交付/成本中心自担〕+档 2 稳定运行）**：双 BOD 候选窗口开启——形态=子母董事会（母 BOD 持保留权仲裁，子 BOD 治 R 面日常），且须 **CEO 显式立法拆分**（宪法级修订：D-13 表+授权矩阵+名址前缀律 r- 系全面启用联动）。
- 量化判据候选（与 LG-033 孵化判据三触发同族）：①R 面任务线连续一季度自担盈亏读数 ②R 面→BOD 升级件量/月低于设定线（反向指标：本地决策够用则不拆）③跨面协调件占比趋势。

## ④ 治理连续性（CEO 离场代行权三案）

- **全自动案**：保留权三类由 BOD 按成文宪法代行——前置件=**三类保留权清单正身成文**（现役差距：审批权限定则「三类保留」系引用、清单本体未见正身，全仓勘验在卷）。
- **半自动案（推荐现役目标态）**：保留权三类冻结候 CEO 回场裁决（低频）+BOD 全权代行保留外+**重大不可逆操作双人令制**（BOD 决+COS 复核令+事后 CEO 追认窗）。
- **人工案**：BOD 全停候 CEO——仅宜短窗（治理冻结态，爆溃 SOP 同族）。
- 与数量决策的关系：无论哪案，**代行主体必须单一**——双 BOD 在 CEO 离场时=两受托面争代行权，连续性最差。④反向加强①。

## ⑤ 与 D-17/三类保留权的关系

- D-17（运行面关键连接变更须 CEO 明令）=保留权具体化的先例条目；但保留权清单本体未成文——**本议题治理副产品=保留权清单成文动议（CAO 域自领）**：清单成文后，BOD 边界/双 BOD 触发/代行权边界/升级路径全部机械化可查。
- 升级路径影响：R 面自治扩权=**授权清单加行（非 BOD 加面）**；仅当授权清单长到「R 面日常治理 90%+ 自决且清单维护成本>双面治理成本」时，档 3 双 BOD 才经济——数量问题本质是清单维护成本问题。

## 四约束贯穿自检

| 约束 | 本立场符合性 |
| --- | --- |
| CEO 最终权威不可代理 | ✓ 三案均保三类升 CEO；代理权单源原则 |
| 三类保留权始终升 CEO | ✓ 且推动清单成文使其可执行（④前置件） |
| R 面独立性不预设终点 | ✓ 档 3 窗口真实存在，非永久单面教条 |
| 治理架构服务业务不反过来 | ✓ 数量跟随 R 面经营责任面演进，档 1 不预支档 3 结构 |
