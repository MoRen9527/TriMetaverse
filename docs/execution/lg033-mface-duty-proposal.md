## 二、架构（双位图）

- **交互位**=本地 session COS（小贾，全工具，指挥链中枢，交互密集时段主）
- **值班位**=服务器 session COS（全工具，sg，急件处置+临时 spawn+通知归位，夜间/自动时段主）
- **共用蓄水池**（git 三端同步磁盘真源）：台账+常驻指令区（+主备标记）+快照+升级日志（值班位专写）+任务书/提案
- **主备标记轮换**：谁主事谁写主账

## 三、五组件

1. **双位定义**：双位同全工具无白名单
2. **蓄水池写分区**：交互位=主账+常驻指令区；值班位=升级日志分区（禁写主账）；主备标记=常驻指令区一字段
3. **交接协议**：轮换规则（交互密集→本地主；值班自动化→服务器主）；交接=翻主备标记+快照一记（≤1 分钟零对话搬运）
4. **re-baseline 协议**：条件式（磁盘有变化才刷）+靶向（只读变更分区）+推拉结合（值班位写盘→推消息给交互位；交互位自写不推=防环）
5. **机械 watcher**：**TriMLC daemon（M 面）**增文件监视（蓄水池分区 mtime/哈希，零 token）→事件唤醒对应位；夜间仅机械层值守（**面归属定则 2026-09-08 CEO 亲定：M 面函数归 M 面件——TriRLC=R 面不参与 M 面值班，watcher 实装位裁定⑧由 TriRLC 勘正为 TriMLC**；TriRLC letters/ProcessSupervisor=R 面或参照资产，M 面所需能力照 TriMMC 移植先例走移植不走依赖）
