## 2. 中央摘要

- 这门 lab 通过 guided-local + manual-capture 方式，让学习者跑通 CLI 的最小学习闭环。
- 重点不是远端沙箱，而是本地命令面、验证面和越界边界。
- lab contract 要求学习者能写出调用链、解释越界失败并回到完整工作流。
