## 1. 文档定位

本文件是 TriMetaverse 对 TriTraining 的 TriMetaverse 专题课程体系架构发布侧摘要。

## 2. 中央摘要

- TriMetaverse 的课程体系采用混合式架构，而不是只按模块或只按概念域组织。
- 顶层按学习者理解路径，中层按 AI / Web3 / 元宇宙主轴，底层按模块专题与工作流实操承接。
- Employee Source Kit CLI 和 Employee Host Publish 发布链都应挂在工作流与 project-run 层。
